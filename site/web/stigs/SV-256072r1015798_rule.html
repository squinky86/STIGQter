STIGQter: STIG Summary: Riverbed NetProfiler Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

Fix Recommendation

Go to Administration >> Audit Trail.

Click "Audit Settings".

Under "Logging Settings", select "Log all Audit Events".

Click "OK" to save the settings.

Check Contents

Enable all DOD-required audit requirements, including changes to user accounts and use of privileged functions.

Go to Administration >> Audit Trail.

Click "Audit Settings".

Check under "Logging Settings".

If "Log all Audit Events" is not selected, this is a finding.
