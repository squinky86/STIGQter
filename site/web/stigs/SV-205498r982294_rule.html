STIGQter: STIG Summary: Mainframe Product Security Requirements Guide Version: 3 Release: 5 Benchmark Date: 01 Jul 2026:

The Mainframe Product must enforce password complexity by requiring that at least one numeric character be used.

DISA Rule

SV-205498r982294_rule

Vulnerability Number

V-205498

Group Title

Rule Version

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the Mainframe Product account management settings to require the use of at least one numeric character in passwords.

Check Contents

If the Mainframe Product employs an external security manager (ESM) for all account management functions, this is not applicable.

Examine user account management configurations.

If the Mainframe Product account management configurations do not require at least one numeric character be used in passwords, this is a finding.
