STIGQter: STIG Summary: Riverbed NetProfiler Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

The Riverbed NetProfiler must be configured to use an authentication server to authenticate users prior to granting administrative access.

Fix Recommendation

This requirement does not apply to the local account of last resort or system accounts.

Go to Administration >> Account Management >> Remote Authentication.

Configure and enable RADIUS, TACACS+, or SAML 2.0.

The following is an example using RADIUS. Refer to the user's guide for instructions for TACACS+ or SAML.

Check Contents

Go to Administration >> Account Management >> Remote Authentication.

Verify that RADIUS, TACACS+, or SAML 2.0 are enabled and configured.

If this is not true, this is a finding.
