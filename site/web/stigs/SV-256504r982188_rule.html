STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Photon OS Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 30 Jan 2025:

The Photon operating system must be configured so that passwords for new users are restricted to a 24-hour minimum lifetime.

DISA Rule

SV-256504r982188_rule

Vulnerability Number

V-256504

Group Title

SRG-OS-000075-GPOS-00043

Rule Version

PHTN-30-000027

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Navigate to and open:

/etc/login.defs

Modify the "PASS_MIN_DAYS" line to the following:

PASS_MIN_DAYS 1

Check Contents

At the command line, run the following command:

# grep "^PASS_MIN_DAYS" /etc/login.defs

If "PASS_MIN_DAYS" is not set to "1", this is a finding.
