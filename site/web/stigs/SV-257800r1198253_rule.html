STIGQter: STIG Summary: Red Hat Enterprise Linux 9 Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

RHEL 9 must restrict exposed kernel pointer addresses access.

DISA Rule

SV-257800r1198253_rule

Vulnerability Number

V-257800

Group Title

SRG-OS-000132-GPOS-00067

Rule Version

RHEL-09-213025

Severity

CAT II

CCI(s)

  • CCI-001082 - Separate user functionality, including user interface services, from system management functionality.
  • CCI-002824 - Implement organization-defined controls to protect its memory from unauthorized code execution.

Weight

10

Fix Recommendation

Configure RHEL 9 to restrict exposed kernel pointer addresses access.

Create a drop-in if it does not already exist:

$ sudo vi /etc/sysctl.d/99-kernel_kptr_restrict.conf

Add the following to the file:
kernel.kptr_restrict = 1

Reload settings from all system configuration files with the following command:

$ sudo sysctl --system

Check Contents

Verify RHEL 9 is configured to restrict exposed kernel pointer address access.

Verify the runtime status of the "kernel.kptr_restrict" kernel parameter with the following command:

$ sudo sysctl kernel.kptr_restrict
kernel.kptr_restrict = 1

If "kernel.kptr_restrict" is not set to "1" or is missing, this is a finding.
