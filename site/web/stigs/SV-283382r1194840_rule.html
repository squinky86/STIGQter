STIGQter: STIG Summary: HPE Alletra Storage ArcusOS Network Device Management Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Feb 2026:

The HPE Alletra Storage ArcusOS device must enforce password complexity by requiring at least one uppercase character, one lowercase character, one numeric character, and one special character be used.

DISA Rule

SV-283382r1194840_rule

Vulnerability Number

V-283382

Group Title

SRG-APP-000166-NDM-000254

Rule Version

ASMP-ND-000420

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the system to require complex passwords with the following command:

Cli% setsys MinimumPWCharacterClasses 4

Check Contents

Verify the system is configured to require complex passwords for local accounts with the following command:

cli% showsys -d
