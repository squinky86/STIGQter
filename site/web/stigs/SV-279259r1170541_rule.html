STIGQter: STIG Summary: Symantec Edge SWG NDM Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Apr 2026:

The Edge SWG must enforce a 60-day password lifetime.

DISA Rule

SV-279259r1170541_rule

Vulnerability Number

V-279259

Group Title

Rule Version

Severity

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

1. Log in to the Edge SWG SSH CLI.
2. Enter "enable" and "configure terminal".
3. Enter "security local-user-list edit local".
4. Enter "max-password-age 60".

Check Contents

1. Log in to the Edge SWG SSH CLI.
2. Enter "enable" and "configure terminal".
3. Enter "security local-user-list edit local".
4. Enter "view".

If the "Password expiration:" and "Max password age:" do not state "60 days", this is a finding.
