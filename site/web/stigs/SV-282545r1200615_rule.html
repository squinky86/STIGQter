STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

The TOSS 5 systemd-journald service must be enabled.

DISA Rule

CCI(s)

  • CCI-001665 - Preserve organization-defined system state information in the event of a system failure.

Weight

10

Fix Recommendation

Enable the "systemd-journald" service using the following command:

$ sudo systemctl enable --now systemd-journald

Check Contents

Verify "systemd-journald" is active on TOSS 5 using the following command:

$ systemctl is-active systemd-journald

active

If the "systemd-journald" service is not active, this is a finding.
