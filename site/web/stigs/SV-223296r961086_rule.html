STIGQter: STIG Summary: Microsoft Office 365 ProPlus Security Technical Implementation Guide Version: 3 Release: 5 Benchmark Date: 01 Apr 2026:

Add-on Management must be enabled for all Office 365 ProPlus programs.

DISA Rule

SV-223296r961086_rule

Vulnerability Number

V-223296

Group Title

SRG-APP-000207

Rule Version

O365-CO-000014

Severity

CAT II

CCI(s)

  • CCI-001662 - Take organization-defined corrective action when organization-defined unacceptable mobile code is identified.

Weight

10

Fix Recommendation

Set the policy value for Computer Configuration >> Administrative Templates >> Microsoft Office 2016 (Machine) >> Security Settings >> IE Security "Add-on Management" to "Enabled" and select the check boxes for all installed Office programs.

Check Contents

Verify the policy value for Computer Configuration >> Administrative Templates >> Microsoft Office 2016 (Machine) >> Security Settings >> IE Security "Add-on Management" is set to "Enabled" and the check box is selected for every installed Office program.

Use the Windows Registry Editor to navigate to the following key:

HKLM\Software\Microsoft\Internet Explorer\Main\FeatureControl\FEATURE_ADDON_MANAGEMENT

If the value for each installed Office Program is REG_DWORD = 1, this is not a finding.
