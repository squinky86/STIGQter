STIGQter: STIG Summary: Apache Server 2.4 Windows Server Security Technical Implementation Guide Version: 3 Release: 4 Benchmark Date: 01 Apr 2026:

The Apache web server must not be a proxy server.

DISA Rule

SV-214320r1051286_rule

Vulnerability Number

V-214320

Group Title

Rule Version

Severity

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

Open the <'INSTALL PATH'>\conf\httpd.conf file with an editor and search for the following directive:

ProxyRequests

Set the directive to a value of "off".

Restart the Apache service.

Check Contents

If the server has been approved to be a proxy server, this requirement is Not Applicable.

Open the <'INSTALL PATH'>\conf\httpd.conf file with an editor and search for the following directive:

ProxyRequests

If the ProxyRequests directive is set to "On", this is a finding.
