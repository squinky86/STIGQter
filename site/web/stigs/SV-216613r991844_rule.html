STIGQter: STIG Summary: Cisco IOS Router RTR Security Technical Implementation Guide Version: 3 Release: 4 Benchmark Date: 01 Oct 2025:

The Cisco PE router must be configured to have each VRF with the appropriate Route Distinguisher (RD).

DISA Rule

SV-216613r991844_rule

Vulnerability Number

V-216613

Group Title

SRG-NET-000512-RTR-000007

Rule Version

CISC-RT-000650

Severity

CAT II

CCI(s)

  • CCI-004931 - Establish organization-defined alternate communications paths for system operations organizational command and control.

Weight

10

Fix Recommendation

Configure the correct RD for each VRF.

R5(config)#ip vrf CUST1
R5(config-vrf)#rd 13:13
R5(config-vrf)#end

Check Contents

Review the design plan for MPLS/L3VPN to determine what RD have been assigned for each VRF. Review the router configuration and verify that the correct RD is configured for each VRF. In the example below, route distinguisher 13:13 has been configured for customer 1.

ip vrf CUST1
rd 13:13

Note: This requirement is only applicable for MPLS L3VPN implementations.

If the wrong RD has been configured for any VRF, this is a finding.
