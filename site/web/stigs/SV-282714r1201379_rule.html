STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

The TOSS 5 SSH daemon must display the date and time of the last successful account logon upon an SSH logon.

DISA Rule

SV-282714r1201379_rule

Vulnerability Number

V-282714

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000260

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure the SSH daemon to provide users with feedback on when account accesses last occurred.

Add the following line in "/etc/ssh/sshd_config" or uncomment the line and set the value to "yes":

PrintLastLog yes

Restart the SSH service for changes to take effect:

$ sudo systemctl restart sshd.service

Check Contents

Verify the SSH daemon provides users with feedback on when account accesses last occurred using the following command:

$ sudo /usr/sbin/sshd -dd 2>&1 | awk '/filename/ {print $4}' | tr -d '\r' | tr '\n' ' ' | xargs sudo grep -iH '^\s*printlastlog'

PrintLastLog yes

If the "PrintLastLog" keyword is set to "no", the returned line is commented out, or no output is returned, this is a finding.
