ACF2 PSWD GSO record value must be set to require at least one numeric character be used.

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the Password options to include "PSWDALPH".

Check Contents

From an ACF command screen enter:
SET CONTROL(GSO)
LIST PSWD

If "PSWDALPH" is coded, this is not a finding.
