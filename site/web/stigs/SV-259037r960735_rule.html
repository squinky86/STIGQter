STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance Lookup Service Security Technical Implementation Guide Version: 2 Release: 2 Benchmark Date: 01 Jul 2026:

The vCenter Lookup service must limit the number of maximum concurrent connections permitted.

DISA Rule

SV-259037r960735_rule

Vulnerability Number

V-259037

Group Title

SRG-APP-000001-AS-000001

Rule Version

VCLU-80-000001

Severity

CAT II

CCI(s)

  • CCI-000054 - Limit the number of concurrent sessions for each organization-defined account and/or account type to an organization-defined number.
  • CCI-002385 - Protect against or limit the effects of organization-defined types of denial of service events.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-lookupsvc/conf/server.xml

Navigate to the <Executor> node with the name of tomcatThreadPool and configure with the value "maxThreads="300"".

Note: The <Executor> node should be configured similar to the following:

<Executor maxThreads="300"
minSpareThreads="50"
name="tomcatThreadPool"
namePrefix="tomcat-http--"/>

Restart the service with the following command:

# vmon-cli --restart lookupsvc

Check Contents

At the command prompt, run the following command:

# xmllint --xpath '/Server/Service/Executor[@name="tomcatThreadPool"]/@maxThreads' /usr/lib/vmware-lookupsvc/conf/server.xml

Expected result:

maxThreads="300"

If the output does not match the expected result, this is a finding.
