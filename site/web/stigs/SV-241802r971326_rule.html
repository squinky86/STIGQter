STIGQter: STIG Summary: Jamf Pro v10.x EMM Security Technical Implementation Guide Version: 3 Release: 1 Benchmark Date: 24 Jul 2024:

MySQL database backups must be scheduled in Jamf Pro EMM.

DISA Rule

SV-241802r971326_rule

Vulnerability Number

V-241802

Group Title

PP-MDM-991000

Rule Version

JAMF-10-100110

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Schedule MySQL of database backups in Jamf Pro EMM.

The procedure is found in the following Jamf Knowledge Base article:

https://www.jamf.com/jamf-nation/articles/579/title

Check Contents

Verify MySQL of database backups have been scheduled in Jamf Pro EMM.

1. Open "Jamf Server Tools".
2. Click "Scheduled Backups" in the sidebar.
3. Verify backups are scheduled.

If MySQL of database backups have not been scheduled in Jamf Pro EMM, this is a finding.
