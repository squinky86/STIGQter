STIGQter: STIG Summary: Canonical Ubuntu 22.04 LTS Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

Ubuntu 22.04 LTS must configure the "/var/log" directory to be owned by "root".

DISA Rule

SV-260508r958566_rule

Vulnerability Number

V-260508

Group Title

SRG-OS-000206-GPOS-00084

Rule Version

UBTU-22-232120

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Configure Ubuntu 22.04 LTS to have root own the "/var/log" directory by using the following command:

$ sudo chown root /var/log

Check Contents

Verify Ubuntu 22.04 LTS configures the "/var/log" directory to be owned by "root" by using the following command:

$ stat -c "%n %U" /var/log
/var/log root

If the "/var/log" directory is not owned by "root", this is a finding.
