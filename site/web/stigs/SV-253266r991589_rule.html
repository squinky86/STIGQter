STIGQter: STIG Summary: Microsoft Windows 11 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

Alternate operating systems must not be permitted on the same system.

DISA Rule

SV-253266r991589_rule

Vulnerability Number

V-253266

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

WN11-00-000055

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Ensure Windows 11 is the only operating system on a device. Remove alternate operating systems.

Check Contents

Verify the system does not include other operating system installations.

Run "Advanced System Settings".
Select the "Advanced" tab.
Click the "Settings" button in the "Startup and Recovery" section.

If the drop-down list box "Default operating system:" shows any operating system other than Windows 11, this is a finding.
