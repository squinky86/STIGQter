STIGQter: STIG Summary: Cisco IOS XE Router NDM Security Technical Implementation Guide Version: 3 Release: 7 Benchmark Date: 01 Apr 2026:

The Cisco device must be configured to audit all administrator activity.

DISA Rule

SV-215815r1186328_rule

Vulnerability Number

V-215815

Group Title

SRG-APP-000080-NDM-000220

Rule Version

CISC-ND-000210

Severity

CAT II

CCI(s)

  • CCI-000166 - Provide irrefutable evidence that an individual (or process acting on behalf of an individual) falsely denying having performed organization-defined actions to be covered by non-repudiation.
  • CCI-002234 - Log the execution of privileged functions.
  • CCI-000172 - Generate audit records for the event types defined in AU-2 c that include the audit record content defined in AU-3.

Weight

10

Fix Recommendation

Configure the router to log administrator activity as shown in the example below.

R1(config)#logging userinfo
R1(config)#archive
R1(config-archive)#log config
R1(config-archive-log-cfg)#logging enable
R1(config-archive-log-cfg)#logging size 1000
R1(config-archive-log-cfg)#notify syslog contenttype plaintext
R1(config-archive-log-cfg)#hidekeys
R1(config-archive-log-cfg)#end
