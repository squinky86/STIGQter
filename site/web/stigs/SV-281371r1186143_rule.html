STIGQter: STIG Summary: Soaring Software Solutions TCMax 9.x Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Feb 2026:

TCMax must enforce a minimum 15-character password length.

DISA Rule

SV-281371r1186143_rule

Vulnerability Number

V-281371

Group Title

SRG-APP-000164

Rule Version

TCMA-09-000062

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

1. Using an account of appropriate privileges to access TCMax, go to Settings >> User Options.

2. Click the "Configure" menu option at the top of the window, then click "Account Security Policy".

3. Check the "Enable Password Enforcement Policy" box.

4. Set the "Minimum Length" value to "15" or greater.

Check Contents

1. Using an account of appropriate privileges to access TCMax, go to Settings >> User Options.

2. Click the "Configure" menu option at the top of the window, then click "Account Security Policy".

On the "Password Enforcement" tab, if the "Enable Password Enforcement Policy" box is unchecked or the "Minimum Length" value is less than "15", this is a finding.
