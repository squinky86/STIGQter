STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

The TOSS 5 /etc/shadow file must be group-owned by root.

DISA Rule

SV-282664r1200972_rule

Group Title

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the group of the file /etc/shadow to root using the following command:

$ sudo chgrp root /etc/shadow

Check Contents

Verify the group ownership of the "/etc/shadow" file using the following command:

$ sudo stat -c "%G %n" /etc/shadow

root /etc/shadow

If "/etc/shadow" file does not have a group owner of "root", this is a finding.
