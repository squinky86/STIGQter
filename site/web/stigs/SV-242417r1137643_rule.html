STIGQter: STIG Summary: Kubernetes Security Technical Implementation Guide Version: 2 Release: 6 Benchmark Date: 01 Apr 2026:

Kubernetes must separate user functionality.

DISA Rule

SV-242417r1137643_rule

Vulnerability Number

V-242417

Group Title

SRG-APP-000211-CTR-000530

Rule Version

CNTR-K8-001360

Severity

CAT II

CCI(s)

  • CCI-001082 - Separate user functionality, including user interface services, from system management functionality.

Weight

10

Fix Recommendation

Move any user pods that are present in the Kubernetes system namespaces to user specific namespaces.

Check Contents

On the Control Plane, run the command:
kubectl get pods --all-namespaces

Review the namespaces and pods that are returned. Kubernetes system namespaces are kube-node-lease, kube-public, and kube-system.

If any user pods are present in the Kubernetes system namespaces, this is a finding.
