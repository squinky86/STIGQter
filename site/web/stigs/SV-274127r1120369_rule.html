STIGQter: STIG Summary: Amazon Linux 2023 Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 01 Jul 2026:

Amazon Linux 2023 must ensure the /var/log directory be group-owned by root.

DISA Rule

SV-274127r1120369_rule

Vulnerability Number

V-274127

Group Title

Rule Version

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Configure Amazon Linux 2023 so that the "/var/log" is group-owned "root" with the following command:

$ sudo chgrp root /var/log

Check Contents

Verify Amazon Linux 2023 is configured so the "/var/log" directory is group-owned by root with the following command:

$ stat -c "%G %n" /var/log
root /var/log

If "/var/log" does not have a group owner of "root", this is a finding.
