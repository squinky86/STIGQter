STIGQter: STIG Summary: BlackBerry UEM Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 22 Jan 2021:

The BlackBerry UEM server platform must be protected by a DoD-approved firewall.

DISA Rule

SV-224382r604136_rule

Vulnerability Number

V-224382

Group Title

PP-MDM-431005

Rule Version

BUEM-00-200010

Severity

CAT II

CCI(s)

  • CCI-000382 - Configure the system to prohibit or restrict the use of organization-defined prohibited or restricted functions, system ports, protocols, software, and/or services.

Weight

10

Fix Recommendation

Install a DoD-approved firewall.

Check Contents

Review the BlackBerry UEM server platform configuration to determine whether a DoD-approved firewall is installed or if the platform operating system provides a firewall service that can restrict both inbound and outbound traffic by TCP/UDP port and IP address.

If there is not a host-based firewall present on the BlackBerry UEM server platform, this is a finding.
