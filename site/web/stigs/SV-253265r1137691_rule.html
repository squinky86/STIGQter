STIGQter: STIG Summary: Microsoft Windows 11 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

Local volumes must be formatted using NTFS.

DISA Rule

SV-253265r1137691_rule

Vulnerability Number

V-253265

Group Title

SRG-OS-000080-GPOS-00048

Rule Version

WN11-00-000050

Severity

CAT I

CCI(s)

  • CCI-000213 - Enforce approved authorizations for logical access to information and system resources in accordance with applicable access control policies.

Weight

10

Fix Recommendation

Format all local volumes to use NTFS.

Check Contents

Run "Computer Management".
Navigate to Storage >> Disk Management.

If the "File System" column does not indicate "NTFS" for each volume assigned a drive letter, this is a finding.

This does not apply to system partitions such the Recovery and EFI System Partition.
