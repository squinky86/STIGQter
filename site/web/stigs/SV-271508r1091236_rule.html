STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must have the rsyslog package installed.

DISA Rule

SV-271508r1091236_rule

Vulnerability Number

V-271508

Group Title

SRG-OS-000479-GPOS-00224

Rule Version

OL09-00-000350

Severity

CAT II

CCI(s)

  • CCI-001851 - Transfer audit logs per organization-defined frequency to a different system, system component, or media than the system or system component conducting the logging.
  • CCI-000154 - Provide the capability to centrally review and analyze audit records from multiple components within the system.

Weight

10

Fix Recommendation

The rsyslogd package can be installed with the following command:

$ sudo dnf install -y rsyslogd

Check Contents

Verify that OL 9 has the rsyslogd package installed with the following command:

$ dnf list --installed rsyslog
Installed Packages
rsyslog.x86_64 8.2310.0-4.el9 @AppStream

If the rsyslogd package is not installed, this is a finding.
