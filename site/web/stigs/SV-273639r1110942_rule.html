STIGQter: STIG Summary: RUCKUS ICX Router Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 27 May 2025:

The RUCKUS ICX Router must be configured to limit the number of mroute states resulting from Internet Group Management Protocol (IGMP) and Multicast Listener Discovery (MLD) Host Membership Reports.

Weight

10

Fix Recommendation

Configure the "system-max pim-hw-cache" and "system-max pim6-hw-cache" values to be above zero. (Reboot may be required to take effect.)

ICX(config)#system-max pim-hw-cache 256
ICX(config)#system-max pim6-hw-cache 256

Check Contents

View the "show default value" output for the pim-hw-cache and pim6-hw-cache values. If either number is zero, this is a finding.
