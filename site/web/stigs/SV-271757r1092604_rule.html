STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 file systems must not contain shosts.equiv files.

DISA Rule

SV-271757r1092604_rule

Vulnerability Number

V-271757

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

OL09-00-002419

Severity

CAT I

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Remove any found "shosts.equiv" files from the system.

$ sudo rm /[path]/[to]/[file]/shosts.equiv

Check Contents

Verify that OL 9 has no "shosts.equiv" files on the system with the following command:

$ sudo find / -name shosts.equiv

If a "shosts.equiv" file is found, this is a finding.
