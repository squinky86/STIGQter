STIGQter: STIG Summary: Apache Server 2.4 UNIX Site Security Technical Implementation Guide Version: 2 Release: 7 Benchmark Date: 01 Jul 2026:

The Apache web server must allow mappings to unused and vulnerable scripts to be removed.

DISA Rule

SV-214282r960963_rule

Vulnerability Number

V-214282

Group Title

SRG-APP-000141-WSR-000082

Rule Version

AS24-U2-000310

Severity

CAT II

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

Determine the location of the "HTTPD_ROOT" directory and the "httpd.conf" file:

# apachectl -V | egrep -i 'httpd_root|server_config_file'
-D HTTPD_ROOT="/etc/httpd"
-D SERVER_CONFIG_FILE="conf/httpd.conf"

Remove any scripts in "cgi-bin" directory if they are not needed for application operation.

Ensure this process is documented and approved by the ISSO.

Review "Script", "ScriptAlias" or "ScriptAliasMatch", or "ScriptInterpreterSource" directives.

Go into each directory and locate "cgi-bin" files.

If any scripts are present that are not needed for application operation, this is a finding.
