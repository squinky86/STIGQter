STIGQter: STIG Summary: Mainframe Product Security Requirements Guide Version: 3 Release: 5 Benchmark Date: 01 Jul 2026:

The Mainframe Product must update malicious code protection mechanisms whenever new releases are available in accordance with organizational configuration management procedures.

Check Contents

If the Mainframe Product has no function or capability for providing malicious code scanning or protection, this is not applicable.

Examine installation and configuration settings.

If the Mainframe Product is not configured to install new releases using organizational-defined configuration management procedure, this is a finding.
