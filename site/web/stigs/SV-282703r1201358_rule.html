STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must prevent Internet Protocol version 6 (IPv6) Internet Control Message Protocol (ICMP) redirect messages from being accepted.

DISA Rule

SV-282703r1201358_rule

Vulnerability Number

V-282703

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000231

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure TOSS 5 to prevent IPv6 ICMP redirect messages from being accepted.

Add or edit the following line in a single system configuration file, in the "/etc/sysctl.d/" directory:

net.ipv6.conf.default.accept_redirects = 0

Load settings from all system configuration files using the following command:

$ sudo sysctl --system

Check Contents

Verify TOSS 5 will not accept IPv6 ICMP redirect messages.

Note: If IPv6 is disabled on the system, this requirement is not applicable.

Check the value of the default "accept_redirects" variables using the following command:

$ sudo sysctl net.ipv6.conf.default.accept_redirects

net.ipv6.conf.default.accept_redirects = 0

If the returned line does not have a value of "0", or a line is not returned, this is a finding.
