STIGQter: STIG Summary: Microsoft Defender Antivirus Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

Microsoft Defender AV must be configured to turn on e-mail scanning.

DISA Rule

SV-213451r961092_rule

Vulnerability Number

V-213451

Group Title

SRG-APP-000210

Rule Version

WNDF-AV-000027

Severity

CAT II

CCI(s)

  • CCI-001170 - Prevents the automatic execution of mobile code in organization-defined software applications.

Weight

10

Fix Recommendation

Set the policy value for Computer Configuration >> Administrative Templates >> Windows Components >> Microsoft Defender Antivirus >> Scan >> "Turn on e-mail scanning" to "Enabled".

Check Contents

Verify the policy value for Computer Configuration >> Administrative Templates >> Windows Components >> Microsoft Defender Antivirus >> Scan >> "Turn on e-mail scanning" is set to "Enabled".

Procedure: Use the Windows Registry Editor to navigate to the following key:
HKLM\Software\Policies\Microsoft\Windows Defender\Scan

Criteria: If the value "DisableEmailScanning" is REG_DWORD = 0, this is not a finding.
