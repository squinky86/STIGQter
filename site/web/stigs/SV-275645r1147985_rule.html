STIGQter: STIG Summary: Riverbed NetIM OS Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 11 Sep 2025:

Ubuntu OS must have the "apparmor" package installed.

DISA Rule

SV-275645r1147985_rule

Vulnerability Number

V-275645

Group Title

SRG-OS-000312-GPOS-00124

Rule Version

RIIM-OS-431010

Severity

CAT II

CCI(s)

  • CCI-001764 - Prevent program execution in accordance with organization-defined policies, rules of behavior, and/or access agreements regarding software program usage and restrictions; rules authorizing the terms and conditions of software program usage.

Weight

10

Fix Recommendation

Install the "appArmor" package by using the following command:

$ sudo apt-get install apparmor

Check Contents

Verify Ubuntu OS has the "apparmor" package installed by using the following command:

$ dpkg -l | grep apparmor
ii apparmor 3.0.4-2ubuntu2.3 amd64 user-space parser utility for AppArmor

If the "apparmor" package is not installed, this is a finding.
