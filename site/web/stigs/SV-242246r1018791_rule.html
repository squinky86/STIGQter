STIGQter: STIG Summary: Trend Micro TippingPoint NDM Security Technical Implementation Guide Version: 2 Release: 3 Benchmark Date: 02 Apr 2025:

The TippingPoint SMS must be configured to synchronize internal information system clocks using redundant authoritative time sources.

DISA Rule

SV-242246r1018791_rule

Vulnerability Number

V-242246

Group Title

SRG-APP-000373-NDM-000298

Rule Version

TIPP-NM-000400

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.
  • CCI-004928 - Identify a secondary authoritative time source that is in a different geographic region than the primary authoritative time source.
  • CCI-004922 - Synchronize system clocks within and between systems or system components.

Weight

10

Fix Recommendation

In the SMS client, ensure two NTP sources are configured.

1. Select Admin, Server Properties, and Network.
2. Check Enable NTP.
3. Enter a server IPv4 address in NTP Server 1 and NTP Server.
4. Ensure this is done under an approved change window as it will cause a reboot.

Check Contents

In the SMS client, ensure two NTP sources are configured.

1. Select Admin, Server Properties, and Network.
2. If Enable NTP is not checked or at least two NTP servers are not configured under Date/Time, this is a finding.
