STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 crypto policy must not be overridden.

DISA Rule

SV-282602r1200786_rule

Vulnerability Number

V-282602

Group Title

SRG-OS-000396-GPOS-00176

Rule Version

TOSS-05-000470

Severity

CAT II

CCI(s)

  • CCI-002450 - Implement organization-defined types of cryptography for each specified cryptography use.

Weight

10

Fix Recommendation

Configure TOSS 5 to FIPS crypto policy.

$ sudo ln -s /usr/share/crypto-policies/FIPS/<service>.txt /etc/crypto-policies/back-ends/<service>.conf

Replace <service> with every service that is not set to FIPS.

Restart the system for the changes to take effect.

Check Contents
