STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

The TOSS 5 /etc/gshadow- file must have mode 0000 or less permissive to prevent unauthorized access.

DISA Rule

SV-282647r1200921_rule

Vulnerability Number

V-282647

Group Title

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the mode of the file "/etc/gshadow-" to "0000" using the following command:

$ sudo chmod 0000 /etc/gshadow-

Check Contents

Verify the "/etc/gshadow-" file has mode "0000" using the following command:

$ sudo stat -c "%a %n" /etc/gshadow-

0 /etc/gshadow-

If a value of "0" is not returned, this is a finding.
