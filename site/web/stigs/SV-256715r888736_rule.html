STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Lookup Service Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

Lookup Service must not be configured with the "UserDatabaseRealm" enabled.

DISA Rule

SV-256715r888736_rule

Vulnerability Number

V-256715

Group Title

SRG-APP-000141-WSR-000015

Rule Version

VCLU-70-000010

Severity

CAT II

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-lookupsvc/conf/server.xml

Remove all <Realm> nodes.

Restart the service with the following command:

# vmon-cli --restart lookupsvc

Check Contents

At the command prompt, run the following command:

# grep UserDatabaseRealm /usr/lib/vmware-lookupsvc/conf/server.xml

If the command produces any output, this is a finding.
