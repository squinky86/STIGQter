STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance Photon OS 4.0 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 31 Oct 2023:

The Photon operating system must configure the Secure Shell (SSH) SyslogFacility.

DISA Rule

SV-258865r933656_rule

Vulnerability Number

V-258865

Group Title

SRG-OS-000032-GPOS-00013

Rule Version

PHTN-40-000200

Severity

CAT II

CCI(s)

  • CCI-000067 - Employ automated mechanisms to monitor remote access methods.

Weight

10

Fix Recommendation

Navigate to and open:

/etc/ssh/sshd_config

Ensure the "SyslogFacility" line is uncommented and set to the following:

SyslogFacility AUTHPRIV

At the command line, run the following command:

# systemctl restart sshd.service

Check Contents

At the command line, run the following command to verify the running configuration of sshd:

# sshd -T|&grep -i SyslogFacility

Example result:

syslogfacility AUTHPRIV

If "syslogfacility" is not set to "AUTH" or "AUTHPRIV", this is a finding.
