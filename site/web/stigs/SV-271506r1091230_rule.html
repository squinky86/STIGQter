STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must have the fapolicy module installed.

DISA Rule

SV-271506r1091230_rule

Vulnerability Number

V-271506

Group Title

SRG-OS-000370-GPOS-00155

Rule Version

OL09-00-000340

Severity

CAT II

CCI(s)

  • CCI-001774 - Employ a deny-all, permit-by-exception policy to allow the execution of authorized software programs on the system.
  • CCI-001764 - Prevent program execution in accordance with organization-defined policies, rules of behavior, and/or access agreements regarding software program usage and restrictions; rules authorizing the terms and conditions of software program usage.

Weight

10

Fix Recommendation

Install the fapolicyd package with the following command:

$ sudo dnf install -y fapolicyd

Check Contents

Verify that OL 9 fapolicyd package is installed with the following command:

$ dnf list --installed fapolicyd
Installed Packages
fapolicyd.x86_64 1.3.2-100.0.1.el9 @ol9_appstream

If the fapolicyd package is not installed, this is a finding.
