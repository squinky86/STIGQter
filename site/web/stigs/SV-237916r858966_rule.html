CA VM:Secure product Config Delay LOG option must be set to 0.

Fix Recommendation

Configure DELAYLOG = 0 or delete the "DELAYLOG" configuration file record.

Check Contents

Display the CA VM:Secure product Config file.

If the "DELAYLOG" record does not exist, this is not a finding.

If the "DELAYLOG" record is set to "0", this is not a finding.
