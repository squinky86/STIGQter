STIGQter: STIG Summary: IBM zVM Using CA VM:Secure Security Technical Implementation Guide Version: 2 Release: 2 Benchmark Date: 27 Oct 2022:

The IBM z/VM Security Manager must provide a procedure to disable userIDs after 35 days of inactivity.

DISA Rule

SV-237919r649597_rule

Vulnerability Number

V-237919

Group Title

SRG-OS-000118-GPOS-00060

Rule Version

IBMZ-VM-000650

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Develop a procedure that includes the following steps:
- Monitors the time since last logon.
- Checks all userIDs for inactivity more than 35 days.
- If found, the ISSO must suspend an account, but not delete it until it is verified by the local ISSO that the user no longer requires access.
- If verification is not received within 60 days, the account may be deleted.
