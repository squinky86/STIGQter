STIGQter: STIG Summary: Google Android 14 BYOAD Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 13 Mar 2024:

The EMM system supporting the Google Android 14 BYOAD must be configured to detect if the Google Android 14 BYOAD native security controls are disabled.

Fix Recommendation

Configure the EMM system supporting the Google Android 14 BYOAD to detect if the BYOAD native security controls are disabled. The exact procedure will depend on the EMM system used at the site.

Check Contents

Verify the EMM system supporting the Google Android 14 BYOAD has been configured to detect if the BYOAD native security controls are disabled. The exact procedure will depend on the EMM system used at the site.

If the EMM system supporting the Google Android 14 BYOAD is not configured to detect if the BYOAD native security controls are disabled, this is a finding.
