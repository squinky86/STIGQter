STIGQter: STIG Summary: HPE Aruba Networking AOS NDM Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 22 Oct 2024:

AOS must retain the Standard Mandatory DOD Notice and Consent Banner on the screen until the administrator acknowledges the usage conditions and takes explicit actions to log on for further access.

  • CCI-000050 - Retain the notification message or banner on the screen until users acknowledge the usage conditions and take explicit actions to log on to or further access the system.

Weight

10

Fix Recommendation

Configure AOS with the following commands:
configure terminal
banner enforce-accept
write memory

Check Contents

Verify the AOS configuration with the following command:
show running-config | include "banner enforce-accept"

If "banner enforce-accept" is not set, this is a finding.
