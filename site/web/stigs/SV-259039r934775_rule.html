STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance Lookup Service Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 31 Oct 2023:

The vCenter Lookup service must initiate session logging upon startup.

DISA Rule

SV-259039r934775_rule

Vulnerability Number

V-259039

Group Title

SRG-APP-000092-AS-000053

Rule Version

VCLU-80-000013

Severity

CAT II

CCI(s)

  • CCI-001464 - Initiates session audits automatically at system start-up.

Weight

10

Fix Recommendation

Navigate to and open:

/etc/vmware/vmware-vmon/svcCfgfiles/lookupsvc.json

Below the last line of the "PreStartCommandArg" block, add the following line:

"StreamRedirectFile": "%VMWARE_LOG_DIR%/vmware/lookupsvc/lookupsvc_stream.log",

Restart the service with the following command:

# vmon-cli --restart lookupsvc

Check Contents

At the command prompt, run the following command:

# grep StreamRedirectFile /etc/vmware/vmware-vmon/svcCfgfiles/lookupsvc.json

Expected output:

"StreamRedirectFile": "%VMWARE_LOG_DIR%/vmware/lookupsvc/lookupsvc_stream.log",

If no log file is specified for the "StreamRedirectFile" setting, this is a finding.
