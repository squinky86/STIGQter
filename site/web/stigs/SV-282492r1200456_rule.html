STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must have the openssl-pkcs11 package installed.

Group Title

CCI(s)

  • CCI-000766 - Implement multifactor authentication for network access to non-privileged accounts.
  • CCI-000139 - Alert organization-defined personnel or roles within an organization-defined time period in the event of an audit logging process failure.

Weight

10

Fix Recommendation

The "openssl-pkcs11" package can be installed using the following command:

$ sudo dnf install openssl-pkcs11

Check Contents

Verify TOSS 5 has the "openssl-pkcs11" package installed using the following command:

$ sudo dnf list --installed openssl-pkcs11

Example output:

openssl-pkcs.i686 0.4.11-7.el9
openssl-pkcs.x86_64 0.4.11-7.el9

If the "openssl-pkcs11" package is not installed, this is a finding.
