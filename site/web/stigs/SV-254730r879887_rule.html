STIGQter: STIG Summary: BlackBerry Enterprise Mobility Server 3.x Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

If the BlackBerry Connect service is installed on the BlackBerry Enterprise Mobility Server (BEMS), it must be configured to enable the Web Proxy.

Weight

10

Fix Recommendation

Configure Web Proxy Configuration for the Connect service.

1. In the BEMS dashboard under "BlackBerry Services Configuration" click "Connect".
2. Click "Web Proxy".
3. Check the box for "Use Web Proxy".
4. Add "Proxy Address".
5. Add "Proxy Port".
6. Set "Proxy Server Authentication Type" to "Digest".

Check Contents

This requirement is not applicable if the Connect service is not enabled on BEMS.

Verify that Web Proxy Configuration has been configured.

1. Under "BlackBerry Services Configuration" select "Connect".
2. Select "Web Proxy".
3. Confirm "Use Web Proxy" has been checked.

If "Use Web Proxy" has not been selected, this is a finding.
