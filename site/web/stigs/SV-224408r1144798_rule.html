Fix Recommendation

The BMC CONTROL-O systems programmer will verify that any configuration/parameters that are required to control the security of the product are properly configured and syntactically correct. Set the standard values for the BMC CONTROL-O security parameters for the specific Access Control Program (ACP) environment along with additional IOA security parameters with standard values as documented below.

Keyword Value
RUNTDFT OWNER
RUNTCACH 100
AUTOMLOG V
