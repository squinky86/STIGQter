STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

AlmaLinux OS 9 must have the USBGuard package installed.

DISA Rule

SV-269380r1050263_rule

Vulnerability Number

V-269380

Group Title

SRG-OS-000378-GPOS-00163

Rule Version

ALMA-09-035210

Severity

CAT II

CCI(s)

  • CCI-001958 - Authenticate organization-defined devices and/or types of devices before establishing a local, remote, and/or network connection.

Weight

10

Fix Recommendation

Install the usbguard package with the following command:

$ dnf install usbguard

Check Contents

Note: If the system is virtual machine with no virtual or physical USB peripherals attached, this is not a finding.

Verify USBGuard is installed on the operating system with the following command:

$ dnf list installed usbguard

Installed Packages
usbguard.x86_64 1.0.0-15.el9 @AppStream

If the USBGuard package is not installed, ask the SA to indicate how unauthorized peripherals are being blocked.

If there is no evidence that unauthorized peripherals are being blocked before establishing a connection, this is a finding.
