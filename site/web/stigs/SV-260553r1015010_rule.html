STIGQter: STIG Summary: Canonical Ubuntu 22.04 LTS Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

Ubuntu 22.04 LTS must allow users to directly initiate a session lock for all connection types.

DISA Rule

SV-260553r1015010_rule

Vulnerability Number

V-260553

Group Title

SRG-OS-000030-GPOS-00011

Rule Version

UBTU-22-412025

Severity

CAT II

CCI(s)

  • CCI-000057 - The information system initiates a session lock after the organization-defined time period of inactivity.
  • CCI-000060 - Conceal, via the device lock, information previously visible on the display with a publicly viewable image.

Weight

10

Fix Recommendation

Install the "vlock" package by using the following command:

$ sudo apt-get install vlock

Check Contents

Verify Ubuntu 22.04 LTS has the "vlock" package installed by using the following command:

$ dpkg -l | grep vlock
ii vlock 2.2.2-10 amd64 Virtual Console locking program

If "vlock" is not installed, this is a finding.
