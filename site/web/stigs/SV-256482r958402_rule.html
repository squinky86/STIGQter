STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Photon OS Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 30 Jan 2025:

The Photon operating system must set a session inactivity timeout of 15 minutes or less.

DISA Rule

SV-256482r958402_rule

Vulnerability Number

V-256482

Group Title

SRG-OS-000029-GPOS-00010

Rule Version

PHTN-30-000005

Severity

CAT II

CCI(s)

  • CCI-000057 - The information system initiates a session lock after the organization-defined time period of inactivity.
  • CCI-002361 - Automatically terminate a user session after organization-defined conditions or trigger events requiring session disconnect.

Weight

10

Fix Recommendation

Navigate to and open:

/etc/profile.d/tmout.sh

Set its content to the following:

TMOUT=900
readonly TMOUT
export TMOUT
mesg n 2>/dev/null

Check Contents

At the command line, run the following command:

# cat /etc/profile.d/tmout.sh

Expected result:

TMOUT=900
readonly TMOUT
export TMOUT
mesg n 2>/dev/null

If the file "tmout.sh" does not exist or the output does not look like the expected result, this is a finding.
