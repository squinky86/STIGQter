STIGQter: STIG Summary: Nokia Service Router OS 25.x Network Device Management Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 28 Apr 2026:

The Nokia router must be configured to conduct backups of system-level information contained in the information system when changes occur.

DISA Rule

SV-283786r1203403_rule

Vulnerability Number

V-283786

Group Title

SRG-APP-000516-NDM-000340

Rule Version

NOKI-ND-000900

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.
  • CCI-000537 - Conduct backups of system-level information contained in the system per organization-defined frequency that is consistent with recovery time and recovery point objectives.
  • CCI-000539 - Conduct backups of system documentation, including security-related documentation, per an organization-defined frequency that is consistent with recovery time and recovery point objectives.

Weight

10

Fix Recommendation

Manual backups can be initiated using the command below:

- admin save

Check Contents

Verify with the site that system-level backups are done when changes occur (or weekly, whichever is shorter).

These can be via a centralized management system with scheduled backups or manually initiated backups.

If the router is not being maintained by approved backup methods, this is a finding.

If the router does not back up information system documentation, including security-related documentation, when changes occur or weekly, whichever is sooner, this is a finding.
