STIGQter: STIG Summary: z/OS NetView for TSS Security Technical Implementation Guide Version: 7 Release: 2 Benchmark Date: 01 Oct 2025:

NetView Started Task name(s) is not properly identified/defined to the system ACP.

DISA Rule

SV-225584r1146119_rule

Vulnerability Number

V-225584

Group Title

SRG-OS-000104

Rule Version

ZNETT030

Severity

CAT II

CCI(s)

  • CCI-000764 - Uniquely identify and authenticate organizational users and associate that unique identification with processes acting on behalf of those users.

Weight

10

Fix Recommendation

The Systems Programmer and ISSO will ensure that the started task(s) for NetView is properly defined.

Define the started task userid CNMPROC and CNMPSSI for NetView.

Example:

TSS CRE(CNMPROC) DEPT(Dept) NAME('NetView') -
FAC(STC) MASTFAC(NETVIEW) PASSWORD(password,0) -
SOURCE(INTRDR)
TSS CRE(CNMPSSI) DEPT(Dept) NAME('NetView') -
FAC(STC) PASSWORD(password,0) -
SOURCE(INTRDR)
