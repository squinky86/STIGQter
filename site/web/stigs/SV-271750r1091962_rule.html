STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must automatically exit interactive command shell user sessions after 15 minutes of inactivity.

DISA Rule

SV-271750r1091962_rule

Vulnerability Number

V-271750

Group Title

SRG-OS-000163-GPOS-00072

Rule Version

OL09-00-002411

Severity

CAT II

CCI(s)

  • CCI-001133 - Terminate the network connection associated with a communications session at the end of the session or after an organization-defined time period of inactivity.
  • CCI-000057 - The information system initiates a session lock after the organization-defined time period of inactivity.

Weight

10

Fix Recommendation

Configure OL 9 to exit interactive command shell user sessions after 15 minutes of inactivity.

Add or edit the following line in "/etc/profile.d/tmout.sh":

#!/bin/bash

declare -xr TMOUT=900

Check Contents

Verify that OL 9 is configured to exit interactive command shell user sessions after 15 minutes of inactivity or less with the following command:

$ grep -i tmout /etc/profile /etc/profile.d/*.sh
/etc/profile.d/tmout.sh:declare -xr TMOUT=900

If "TMOUT" is not set to "900" or less in a script located in the "/etc/'profile.d/ directory, is missing or is commented out, this is a finding.
