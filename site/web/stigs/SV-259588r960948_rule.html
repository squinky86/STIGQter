STIGQter: STIG Summary: Microsoft Exchange 2019 Edge Server Security Technical Implementation Guide Version: 2 Release: 2 Benchmark Date: 30 Jan 2025:

Exchange audit data must be on separate partitions.

DISA Rule

SV-259588r960948_rule

Vulnerability Number

V-259588

Group Title

SRG-APP-000125

Rule Version

EX19-ED-000050

Severity

CAT II

CCI(s)

  • CCI-001348 - Store audit records on an organization-defined frequency in a repository that is part of a physically different system or system component that the system or component being audited.

Weight

10

Fix Recommendation

Update the EDSP.

Configure the audit log location to be on a partition drive separate from the application.

Check Contents

Review the Email Domain Security Plan (EDSP).

Determine the audit logs' assigned partition.

Note: By default, the logs are located on the application partition in \Program Files\Microsoft\Exchange Server\V15\Logging\.

If the log files are not on a separate partition from the application, this is a finding.
