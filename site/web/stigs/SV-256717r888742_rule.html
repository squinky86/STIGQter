STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Lookup Service Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

Lookup Service must have Multipurpose Internet Mail Extensions (MIMEs) that invoke operating system shell programs disabled.

DISA Rule

SV-256717r888742_rule

Vulnerability Number

V-256717

Group Title

SRG-APP-000141-WSR-000081

Rule Version

VCLU-70-000012

Severity

CAT II

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-lookupsvc/conf/web.xml

Remove all of the following nodes lines:

<mime-type>application/x-csh</mime-type>
<mime-type>application/x-shar</mime-type>
<mime-type>application/x-sh</mime-type>
<mime-type>application/x-ksh</mime-type>

Restart the service with the following command:

# vmon-cli --restart lookupsvc

Note: Delete the entire mime-mapping node for the target mime-type.

Example:

<mime-mapping>
<extension>sh</extension>
<mime-type>application/x-sh</mime-type>
</mime-mapping>

Check Contents

At the command prompt, run the following command:

# grep -En '(x-csh<)|(x-sh<)|(x-shar<)|(x-ksh<)' /usr/lib/vmware-lookupsvc/conf/web.xml

If the command produces any output, this is a finding.
