STIGQter: STIG Summary: Red Hat Enterprise Linux 8 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

The RHEL 8 /var/log directory must have mode 0755 or less permissive.

DISA Rule

SV-230248r1069291_rule

Vulnerability Number

V-230248

Group Title

SRG-OS-000206-GPOS-00084

Rule Version

RHEL-08-010240

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Change the permissions of the directory "/var/log" to "0755" by running the following command:

$ sudo chmod 0755 /var/log

Check Contents

Verify that the "/var/log" directory has a mode of "0755" or less with the following command:

$ sudo stat -c "%a %n" /var/log

755 /var/log

If a value of "0755" or less permissive is not returned, this is a finding.
