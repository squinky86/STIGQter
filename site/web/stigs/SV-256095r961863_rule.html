STIGQter: STIG Summary: Riverbed NetProfiler Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

The Riverbed NetProfiler must be configured to run an operating system release that is currently supported by the vendor.

Fix Recommendation

Check the vendor's website (support.riverbed.com) to verify the current version installed on the NetProfiler appliance is supported.

Go to System >> Update.

Under "Add a different update version", select the" Update File:" radio button, click "Browse", find the update downloaded from a DOD authorized source, and select "Update Now".

Check Contents

Go to System >> Update.

Verify the current version is higher than 10.0.0 and currently supported by the vendor by checking the vendor's website (support.riverbed.com).

If this is not true, this is a finding.
