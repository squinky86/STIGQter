Ax-OS must use multifactor authentication for network access to the files account.

Weight

Fix Recommendation

From the Axonius Toolbox (accessed via SSH) Main Actions Menu, select the following options:

System Actions >> Update files account SSH key

Follow the on-screen prompts to configure key-based authentication.

Check Contents

Have the system administrator (SA) demonstrate logging in to the Axonius host via Secure File Transfer Protocol (SFTP).

Verify the SA is using a password-protected Secure Shell (SSH) key to log in to the system.

If the SA is not using a password-protected SSH key to log in to the system, this is a finding.
