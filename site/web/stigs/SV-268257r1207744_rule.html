Check Contents

Verify that the HYCU device is running a supported version.

Log in to the HYCU Web UI. On the menu on the left side of the page, scroll to the bottom, where it shows the running version of HYCU.

If HYCU version is not on the list of supported versions, as specified in the End-of-Life Milestones and Dates, this is a finding.

Note: The HYCU support portal specifies the HYCU end of life policies. To determine if the system is using a supported version, visit: https://download.hycu.com/docs/HYCU-EOL-dates.pdf.
