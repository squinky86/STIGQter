STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

The root account must be the only account having unrestricted access to an AlmaLinux OS 9 system.

DISA Rule

SV-269291r1050173_rule

Vulnerability Number

V-269291

Group Title

Rule Version

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the UID of any account on the system, other than root which has a UID of "0".

If the account is associated with system commands or applications, the UID should be changed to one greater than "0" but less than "1000". Otherwise, assign a UID of greater than "1000" that has not already been assigned.

Check Contents

Verify that only the "root" account has a UID "0" assignment with the following command:

$ awk -F: '$3 == 0 {print $1}' /etc/passwd

root

If any accounts other than "root" have a UID of "0", this is a finding.
