STIGQter: STIG Summary: VMware NSX-T Manager NDM Security Technical Implementation Guide Version: 1 Release: 3 Benchmark Date: 26 Jul 2023:

The NSX-T Manager must enforce a minimum 15-character password length.

DISA Rule

SV-251780r919231_rule

Vulnerability Number

V-251780

Group Title

SRG-APP-000164-NDM-000252

Rule Version

TNDM-3X-000041

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

From an NSX-T Manager shell, run the following command(s):

> set auth-policy minimum-password-length 15

Check Contents

From an NSX-T Manager shell, run the following command(s):

> get auth-policy minimum-password-length

Expected result:
15 characters

If the "minimum-password-length" is not set to 15 or greater, this is a finding.
