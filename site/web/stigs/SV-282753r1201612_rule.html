STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must define default permissions for the bash shell.

DISA Rule

SV-282753r1201612_rule

Vulnerability Number

V-282753

Group Title

SRG-OS-000480-GPOS-00228

Rule Version

TOSS-05-000316

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure TOSS 5 to define default permissions for all authenticated users using the bash shell.

Add or edit the lines for the "umask" parameter in the "/etc/bashrc" file to "077":

umask 077

Check Contents

Verify the "umask" setting is configured correctly in the "/etc/bashrc" file using the following command:

Note: If the value of the "umask" parameter is set to "000" "/etc/bashrc" file, the severity is raised to a CAT I.

$ grep umask /etc/bashrc

umask 077
umask 077

If the value for the "umask" parameter is not "077", or the "umask" parameter is missing or is commented out, this is a finding.
