AlmaLinux OS 9 must have the postfix package installed.

Fix Recommendation

Install the postfix package with the following command:

$ sudo dnf install postfix

Check Contents

Note: If the admin can demonstrate that there is another system/service to send audit failure notifications to the administrator/ISSO, this control is not applicable.

Verify AlmaLinux OS 9 has the postfix package installed with the following command:

$ dnf list --installed postfix

Example output:

postfix.x86_64 2:3.5.9-24.el9 @AppStream

If the "postfix" package is not installed, this is a finding.
