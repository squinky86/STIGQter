Fix Recommendation

Configure LDAP.

1. From the Admin Console Landing Screen, navigate to Security >> Administrator >> External Authentication" tab.

2. Configure LDAP:
- Select "LDAP" option.
- Click "Edit LDAP Configuration".
- Enter LDAP Details.
- Click "SAVE".

3. If connection is verified, click "Submit Changes".

Check Contents

Verify LDAP is in use.

From the Admin Console Landing Screen, navigate to Security >> Administrator.

If "External Authentication" is set to "NONE", this is a finding.
