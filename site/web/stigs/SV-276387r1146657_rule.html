STIGQter: STIG Summary: Apple visionOS 2 Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 13 May 2026:

Apple visionOS 2 must be configured to display the DOD advisory warning message at startup or each time the user unlocks the device.

DISA Rule

SV-276387r1146657_rule

Vulnerability Number

V-276387

Group Title

PP-MDF-333160

Rule Version

AVOS-02-008400

Severity

CAT III

CCI(s)

  • CCI-000048 - Display an organization-defined system use notification message or banner to users before granting access to the system that provides privacy and security notices consistent with applicable federal laws, Executive Orders, directives, policies, regulations, standards, and guidelines.

Weight

10

Fix Recommendation

Configure the DOD warning banner by the following method (required text is found in the Vulnerability Discussion):

1. By placing the DOD warning banner text in the user agreement signed by each visionOS device user.

Note, Vision Pro does not support the LockScreenFootnote key.

Check Contents

The DOD warning banner can be displayed by the following method (required text is found in the Vulnerability Discussion):

1. By placing the DOD warning banner text in the user agreement signed by each Vision Pro user.

Validation Procedure for Method #1:
Review the signed user agreements for several visionOS device users and verify the agreement includes the required DOD warning banner text.

If, the required warning banner text is not on all signed user agreements reviewed, this is a finding.
