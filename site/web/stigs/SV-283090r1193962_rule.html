STIGQter: STIG Summary: HPE Alletra Storage ArcusOS Web Server Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Feb 2026:

The HPE Alletra Storage ArcusOS device must utilize trusted and authorized certificates.

DISA Rule

SV-283090r1193962_rule

Vulnerability Number

V-283090

Group Title

SRG-APP-000910-WSR-000300

Rule Version

ASMP-WS-001390

Severity

CAT II

CCI(s)

  • CCI-004909 - Include only approved trust anchors in trust stores or certificate stores managed by the organization.

Weight

10

Fix Recommendation

Install the correct certificate for each service using the importcert command.

importcert <SSL_service> [-f] -ca <CA_bundle>
