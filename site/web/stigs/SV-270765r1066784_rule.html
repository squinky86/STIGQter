STIGQter: STIG Summary: Canonical Ubuntu 24.04 LTS Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

Ubuntu 24.04 LTS must configure the /var/log directory to be group-owned by syslog.

DISA Rule

SV-270765r1066784_rule

Vulnerability Number

V-270765

Group Title

SRG-OS-000206-GPOS-00084

Rule Version

UBTU-24-700100

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Configure Ubuntu 24.04 LTS to have syslog group-own the /var/log directory with the following command:

$ sudo chgrp syslog /var/log

Check Contents

Verify that Ubuntu 24.04 LTS configures the /var/log directory to be group-owned by "syslog" with the following command:

$ stat -c "%n %G" /var/log
/var/log syslog

If the "/var/log" directory is not group-owned by syslog, this is a finding.
