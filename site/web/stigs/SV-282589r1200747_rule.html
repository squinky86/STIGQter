Fix Recommendation

Install the "fapolicyd" package using the following command:

$ sudo dnf install fapolicyd

Check Contents

Verify the TOSS 5 "fapolicyd" package is installed using the following command:

$ sudo dnf list --installed fapolicyd

Example output:

fapolicyd.x86_64 1.1-103.el9_0

If the "fapolicyd" package is not installed, this is a finding.
