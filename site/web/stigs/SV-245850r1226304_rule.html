Fix Recommendation

General Information:

This fix is only for unclassified/sensitive media being used in a strictly unclassified physical environment. If all CUI media are in a mixed environment where classified systems and media are in use, then STIG ID IS-03.02.01. applies and this potential vulnerability is NA.

Ensure the following standard is met:

Regardless of media type, the requirement to identify as clearly as possible the information requiring protection remains. Therefore, ensure all unclassified media containing CUI is properly marked according to content. Where it is not feasible to include markings with all of the information required for classified or sensitive documents or media, an explanatory statement that provides the required information shall be included on the item or with the documentation that accompanies it.

While CUI is the primary marking used in DOD, all types of CUI markings must be considered for use as appropriate. For instance: "Law Enforcement Sensitive" is a marking sometimes applied by the Department of Justice and other activities in the law enforcement community, including those within the Department of Defense.
