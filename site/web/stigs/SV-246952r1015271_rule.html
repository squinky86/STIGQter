STIGQter: STIG Summary: NetApp ONTAP DSC 9.x Security Technical Implementation Guide Version: 2 Release: 4 Benchmark Date: 01 Jul 2026:

ONTAP must enforce password complexity by requiring that at least one uppercase character be used.

DISA Rule

SV-246952r1015271_rule

Vulnerability Number

V-246952

Group Title

SRG-APP-000166-NDM-000254

Rule Version

NAOT-IA-000006

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure ONTAP to enforce password complexity by requiring that at least one uppercase character be used for the role admin with "security login role config modify -role admin -passwd-min-uppercase-chars 1".

Check Contents

Use "security login role config show -role admin -fields passwd-min-uppercase-chars" to see the minimum number of uppercase characters required in a password for the role admin.

If ONTAP is not configured to enforce password complexity by requiring that at least one uppercase character be used, this is a finding.
