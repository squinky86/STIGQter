STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance ESX Agent Manager (EAM) Security Technical Implementation Guide Version: 2 Release: 3 Benchmark Date: 01 Jul 2026:

The vCenter ESX Agent Manager service must limit the amount of time that each Transmission Control Protocol (TCP) connection is kept alive.

DISA Rule

SV-259018r960735_rule

Vulnerability Number

V-259018

Group Title

SRG-APP-000001-AS-000001

Rule Version

VCEM-80-000125

Severity

CAT II

CCI(s)

  • CCI-000054 - Limit the number of concurrent sessions for each organization-defined account and/or account type to an organization-defined number.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-eam/web/conf/server.xml

Configure the <Connector> node with the value:

connectionTimeout="60000"

Restart the service with the following command:

# vmon-cli --restart eam

Check Contents

The connection timeout should not be disabled by setting it to "-1".

At the command prompt, run the following command:

# xmllint --xpath "//Connector[@connectionTimeout = '-1']" /usr/lib/vmware-eam/web/conf/server.xml

Expected result:

XPath set is empty

If any connectors are returned, this is a finding.
