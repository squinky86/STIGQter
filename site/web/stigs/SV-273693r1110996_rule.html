STIGQter: STIG Summary: RUCKUS ICX Layer 2 Switch Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 27 May 2025:

The RUCKUS ICX layer 2 switch must have the native VLAN assigned to an ID other than the default VLAN for all 802.1q trunk links.

DISA Rule

SV-273693r1110996_rule

Vulnerability Number

V-273693

Group Title

SRG-NET-000512-L2S-000012

Rule Version

RCKS-L2S-000260

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

If a trunk port (1/2/1 below) also has the default VLAN assigned as the native VLAN (i.e., untagged), remove that interface from the default VLAN.

device# configure terminal
device(config)# default-vlan-id 4505
device(config)# vlan 4505
device(config-vlan-4505)# no untag ethernet 1/2/1
