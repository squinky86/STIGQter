Fix Recommendation

Configure the UEM server to implement replay-resistant authentication mechanisms for network access to nonprivileged accounts.

Check Contents

Requirement is Not Applicable when UEM server is configured to use DoW Central Directory Service for administrator account authentication.

Verify the UEM server implements replay-resistant authentication mechanisms for network access to nonprivileged accounts.

If the UEM server does not implement replay-resistant authentication mechanisms for network access to nonprivileged accounts, this is a finding.
