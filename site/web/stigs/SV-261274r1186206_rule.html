STIGQter: STIG Summary: SUSE Linux Enterprise Micro (SLEM) 5 Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 01 Apr 2026:

The SLEM 5 tool zypper must have gpgcheck enabled.

Weight

10

Fix Recommendation

Configure the SLEM 5 tool zypper to enable gpgcheck.

Add or modify the following line in the "/etc/zypp/zypp.conf" file or remove the line completely, ensuring the default zypper setting is enabled:

gpgcheck = on

Check Contents

Verify the SLEM 5 tool zypper has gpgcheck enabled with the following command:

> grep -i '^gpgcheck' /etc/zypp/zypp.conf

If "gpgcheck" is set to "off", this is a finding.
