STIGQter: STIG Summary: Enterprise Voice, Video, and Messaging Session Management Security Requirements Guide Version: 1 Release: 3 Benchmark Date: 01 Jul 2026:

The Enterprise Voice, Video, and Messaging Session Manager must only use ports, protocols, and services allowed per the Ports, Protocols, and Services Management (PPSM) Category Assurance List (CAL) and Vulnerability Assessments (VAs).

Check Contents

Verify the Enterprise Voice, Video, and Messaging Session Manager only uses ports, protocols, and services allowed per the PPSM CAL and VAs.

If the Enterprise Voice, Video, and Messaging Session Manager uses ports, protocols, and services other than those permitted by the PPSM CAL and VAs, this is a finding.
