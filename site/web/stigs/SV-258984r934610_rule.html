STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance Secure Token Service (STS) Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 31 Oct 2023:

The vCenter STS service must offload log records onto a different system or media from the system being logged.

DISA Rule

SV-258984r934610_rule

Vulnerability Number

V-258984

Group Title

SRG-APP-000358-AS-000064

Rule Version

VCST-80-000081

Severity

CAT II

CCI(s)

  • CCI-001851 - Transfer audit logs per organization-defined frequency to a different system, system component, or media than the system or system component conducting the logging.

Weight

10

Fix Recommendation

Navigate to and open:

/etc/vmware-syslog/vmware-services-sso-services.conf

Create the file if it does not exist.
