STIGQter: STIG Summary: SUSE Linux Enterprise Micro (SLEM) 5 Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 01 Apr 2026:

All SLEM 5 local interactive user home directories must have mode 750 or less permissive.

DISA Rule

SV-261291r1184385_rule

Vulnerability Number

V-261291

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

SLEM-05-232030

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the mode of SLEM 5 local interactive user's home directories to "750". To change the mode of a local interactive user's home directory, use the following command:

Note: The example will be for the user "dosuser".

> sudo chmod 750 /home/dosuser

Check Contents

Note: This may miss interactive users that have been assigned a privileged User Identifier (UID). Evidence of interactive use may be obtained from a number of log files containing system logon information.

Verify the assigned home directory of all SLEM 5 local interactive users has a mode of "750" or less permissive with the following command:

> ls -ld $(awk -F: '($3>=1000)&&($7 !~ /nologin/){print $6}' /etc/passwd)
-rwxr-x--- 1 dosuser users 18 Mar 5 17:6 /home/dosuser

If home directories referenced in "/etc/passwd" do not have a mode of "750" or less permissive, this is a finding.
