IBM RACF SETROPTS RVARYPW values must be properly set.

Fix Recommendation

Configure RACF ensure that the RVARYPW passwords are specified and conform to password requirements documented in RACF0460. The ISSO will evaluate the impact associated with implementation of the control option and develop a plan of action to implement the control option as required.

A sample command for setting both the SWITCH and STATUS passwords are shown here:

SETR RVARYPW(SWITCH(Wxy$8Pqu) STATUS(pbZ0@wL2))

Check Contents

From the ISPF Command Shell enter:

SETROPTS LIST

If the "INSTALLATION DEFINED RVARY PASSWORD IS IN EFFECT" message for both the SWITCH and STATUS functions, this is not a finding.
