CA-ACF2 userids found inactive for more than 35 days must be suspended.

DISA Rule

SV-223498r1225728_rule

Vulnerability Number

V-223498

Group Title

SRG-OS-000118-GPOS-00060

Rule Version

ACF2-ES-000800

Severity

CAT II

CCI(s)

  • CCI-003627 - Disable accounts when the accounts have expired.

Weight

10

Fix Recommendation

Develop a procedure to check all userids for inactivity more than 35 days. If found, the information system security officer (ISSO) must suspend an account, but not delete it until it is verified by the local ISSO that the user no longer requires access. If verification is not received within 60 days, the account may be deleted.

Check Contents

From the ISPF Command Shell enter:
ACF

If every user shows an ACC-DATE=mm/dd/yy within the past 35 days, this is not a finding.

NOTE: VALID FOR INTERACTIVE USERIDS, NOT VALID FOR STARTED TASK USERIDS AND BATCH USERIDS.
