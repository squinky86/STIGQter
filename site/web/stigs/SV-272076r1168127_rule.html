STIGQter: STIG Summary: Cisco ACI Router Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 05 Jan 2026:

The Cisco ACI must not be configured to have any feature enabled that calls home to the vendor.

DISA Rule

SV-272076r1168127_rule

Vulnerability Number

V-272076

Group Title

SRG-NET-000131-RTR-000083

Rule Version

CACI-RT-000016

Severity

CAT II

CCI(s)

  • CCI-002403 - Only allow incoming communications from organization-defined authorized sources routed to organization-defined authorized destinations.

Weight

10

Fix Recommendation

Disable the Call Home feature:
1. Navigate to Admin >> External Data Collectors >> monitoring Destinations >> smart callhome.
2. In the General tab, set the Admin State to "Off".
3. Click "Save".

Check Contents

Verify the ACI configuration under Admin >> External Data Collectors >> monitoring Destinations >> smart callhome/callhome is not setup, and that no Intersight configuration is setup at System >> System Settings >> Intersight Connectivity.

If the Call Home feature is configured to send messages to unauthorized individuals such as Cisco TAC, this is a finding.
