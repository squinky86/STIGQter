STIGQter: STIG Summary: Honeywell Android 13 COPE Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 22 Apr 2025:

The Honeywell Android 13 work profile must be configured to disable the autofill services.

DISA Rule

SV-274421r1100833_rule

Vulnerability Number

V-274421

Group Title

PP-MDF-993300

Rule Version

HONW-13-010500

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure the Honeywell Android 13 device work profile to disable the autofill services.

On the EMM console:

COPE:

1. Open "Set user restrictions".
2. Toggle "Disable autofill" to "ON".

Check Contents

Review the Honeywell Android 13 work profile configuration settings to confirm that autofill services are disabled.

This procedure is performed only on the EMM Administration Console.

On the EMM console:

COPE:

1. Open "Set user restrictions".
2. Verify that "Disable autofill" is toggled to "ON".

If on the EMM console "disallow autofill" is not selected, this is a finding.
