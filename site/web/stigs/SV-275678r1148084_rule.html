STIGQter: STIG Summary: Riverbed NetIM OS Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 11 Sep 2025:

Ubuntu OS must produce audit records and reports containing information to establish when, where, what type, the source, and the outcome for all DOD-defined auditable events and actions in near real time.

Weight

10

Fix Recommendation

Enable and start the "auditd.service" by using the following command:

$ sudo systemctl enable auditd.service --now

Check Contents

Verify the "auditd.service" is enabled and active by using the following commands:

$ systemctl is-enabled auditd.service
enabled

$ systemctl is-active auditd.service
active

If the "auditd.service" is not enabled and active, this is a finding.
