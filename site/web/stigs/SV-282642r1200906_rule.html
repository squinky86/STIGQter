STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

All TOSS 5 local initialization files must have mode 0740 or less permissive.

DISA Rule

SV-282642r1200906_rule

Vulnerability Number

V-282642

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000146

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Set the mode of the local initialization files to "0740" using the following command:

Note: The example will be for the wadea user, who has a home directory of "/home/wadea".

$ sudo chmod 0740 /home/wadea/.<INIT_FILE>

Check Contents

Verify all local initialization files have a mode of "0740" or less permissive using the following command:

Note: The example will be for the "wadea" user, who has a home directory of "/home/wadea".

$ sudo ls -al /home/wadea/.[^.]* | more

-rwxr---- 1 wadea users 896 Mar 10 2011 .profile
-rwxr---- 1 wadea users 497 Jan 6 2007 .login
-rwxr---- 1 wadea users 886 Jan 6 2007 .something

If any local initialization files have a mode more permissive than "0740", and is not documented with the information system security officer (ISSO) as an operational requirement, this is a finding.
