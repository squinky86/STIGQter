STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 SSH daemon must not allow Kerberos authentication.

DISA Rule

SV-282581r1200723_rule

Vulnerability Number

V-282581

Group Title

SRG-OS-000364-GPOS-00151

Rule Version

TOSS-05-000256

Severity

CAT II

CCI(s)

  • CCI-001813 - Enforce access restrictions using organization-defined mechanisms.

Weight

10

Fix Recommendation

Configure the SSH daemon to not allow Kerberos authentication.

Add the following line in "/etc/ssh/sshd_config" or uncomment the line and set the value to "no":

KerberosAuthentication no

Restart the SSH service for changes to take effect:

$ sudo systemctl restart sshd.service

Check Contents

Verify the SSH daemon does not allow Kerberos authentication using the following command:

$ sudo /usr/sbin/sshd -dd 2>&1 | awk '/filename/ {print $4}' | tr -d '\r' | tr '\n' ' ' | xargs sudo grep -iH '^\s*kerberosauthentication'

KerberosAuthentication no

If the value is returned as "yes", the returned line is commented out, no output is returned, and the use of Kerberos authentication has not been documented with the information system security officer (ISSO), this is a finding.
