STIGQter: STIG Summary: IBM z/OS ACF2 Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

CA-ACF2 OPTS GSO record must be set to ABORT mode.

DISA Rule

SV-223422r1225655_rule

Vulnerability Number

V-223422

Group Title

SRG-OS-000001-GPOS-00001

Rule Version

ACF2-ES-000010

Severity

CAT I

CCI(s)

  • CCI-000015 - Support the management of system accounts using (organization-defined automated mechanisms).

Weight

10

Fix Recommendation

Configure the GSO Option for "MODE" to equal "ABORT".

Check Contents

From the ISPF Command Shell enter "ACF" to enter ACF2 Command shell.

Enter "SHOW STATE".

If the "GSO OPTS" record show a "MODE= ABORT", this is not a finding.
