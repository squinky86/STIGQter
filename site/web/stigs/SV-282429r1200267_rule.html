STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must take appropriate action when a critical audit processing failure occurs.

DISA Rule

SV-282429r1200267_rule

Vulnerability Number

V-282429

Group Title

SRG-OS-000046-GPOS-00022

Rule Version

TOSS-05-000462

Severity

CAT II

CCI(s)

  • CCI-000139 - Alert organization-defined personnel or roles within an organization-defined time period in the event of an audit logging process failure.

Weight

10

Fix Recommendation

Configure TOSS 5 to shut down when auditing failures occur.

Add the following line to the bottom of the "/etc/audit/audit.rules" file:

-f 2

Check Contents

Verify the audit service is configured to panic on a critical error using the following command:

$ sudo grep "\-f" /etc/audit/audit.rules

-f 2

If the value for "-f" is not "2", and availability is not documented as an overriding concern, this is a finding.
