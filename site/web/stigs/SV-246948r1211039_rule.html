Fix Recommendation

Configure new administrator active directory users or groups with "security login create -user-or-group-name <user_name> -role admin -authentication-method domain".

Check Contents

Use "security login show -role admin" to see all configured admin users and groups.

If any account, other than the admin account used as the account of last resort, has an authentication method password, this is a finding.
