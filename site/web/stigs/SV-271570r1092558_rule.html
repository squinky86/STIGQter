STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must audit uses of the execve system call.

DISA Rule

SV-271570r1092558_rule

Vulnerability Number

V-271570

Group Title

SRG-OS-000326-GPOS-00126

Rule Version

OL09-00-000715

Severity

CAT II

CCI(s)

  • CCI-002233 - Prevent the organization-defined software from executing at higher privilege levels than users executing the software.
  • CCI-002234 - Log the execution of privileged functions.
  • CCI-004188 - Monitor the use of maintenance tools that execute with increased privilege.

Weight

10

Fix Recommendation

Configure OL 9 to audit the execution of the execve system call.

Add or update the following file system rules to "/etc/audit/rules.d/audit.rules":

-a always,exit -F arch=b32 -S execve -C uid!=euid -F euid=0 -k execpriv
-a always,exit -F arch=b64 -S execve -C uid!=euid -F euid=0 -k execpriv
-a always,exit -F arch=b32 -S execve -C gid!=egid -F egid=0 -k execpriv
-a always,exit -F arch=b64 -S execve -C gid!=egid -F egid=0 -k execpriv

The audit daemon must be restarted for the changes to take effect.

Restart auditd:
$ sudo service auditd restart

Note: Users must reboot to view above results with command "auditctl -l | grep execve".

Check Contents

Verify that OL 9 is configured to audit the execution of the execve system call with the following command:

$ sudo auditctl -l | grep execve
-a always,exit -F arch=b32 -S execve -C uid!=euid -F euid=0 -k execpriv
-a always,exit -F arch=b64 -S execve -C uid!=euid -F euid=0 -k execpriv
-a always,exit -F arch=b32 -S execve -C gid!=egid -F egid=0 -k execpriv
-a always,exit -F arch=b64 -S execve -C gid!=egid -F egid=0 -k execpriv

If the command does not return all lines or the lines are commented out, this is a finding.
