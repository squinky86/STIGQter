STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 SSHD must not allow blank or null passwords.

DISA Rule

SV-282493r1200459_rule

Vulnerability Number

V-282493

Group Title

SRG-OS-000106-GPOS-00053

Rule Version

TOSS-05-000238

Severity

CAT I

CCI(s)

  • CCI-000766 - Implement multifactor authentication for network access to non-privileged accounts.

Weight

10

Fix Recommendation

Configure the system to prevent SSH users from logging on with blank passwords by editing the following line in "etc/ssh/sshd_config":

PermitEmptyPasswords no

Restart the SSH daemon for the settings to take effect:

$ sudo systemctl restart sshd.service

Check Contents

Verify TOSS 5 remote access using SSH prevents logging on with a blank password using the following command:

$ sudo /usr/sbin/sshd -dd 2>&1 | awk '/filename/ {print $4}' | tr -d '\r' | tr '\n' ' ' | xargs sudo grep -iH '^\s*permitemptypasswords'

PermitEmptyPassword no

If the "PermitEmptyPassword" keyword is set to "yes", is missing, or is commented out, this is a finding.
