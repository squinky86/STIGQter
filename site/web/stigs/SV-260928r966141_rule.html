STIGQter: STIG Summary: Mirantis Kubernetes Engine Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

The "Create repository on push" option in MSR must be disabled.

10

Fix Recommendation

If MSR is not being utilized, this is Not Applicable.

Verify the "Create repository on push" option is disabled in MSR:

Log in to the MSR web UI as an administrator and navigate to System >> General Tab >>Repositories Section.

Set the "Create repository on push" slider to off.
