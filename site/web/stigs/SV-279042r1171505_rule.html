STIGQter: STIG Summary: Adobe ColdFusion Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Jul 2026:

ColdFusion must have Remote Development Services (RDS) disabled.

DISA Rule

Group Title

Rule Version

Severity

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

Disable RDS.

1. From the Admin Console Landing Screen, navigate to Security >> RDS.

2. Uncheck "Enable RDS Service".

3. Select "Submit Changes".

Check Contents

Verify RDS is disabled.

From the Admin Console Landing Screen, navigate to Security >> RDS.

If "Enable RDS Service" is checked, this is a finding.
