STIGQter: STIG Summary: Nokia Service Router OS 25.x Network Device Management Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 28 Apr 2026:

The Nokia router must be configured to synchronize system clocks within and between systems or system components.

Weight

10

Fix Recommendation

Configure the Nokia router to synchronize system clocks within and between systems or system components.

Configure NTP server to be used for timing using the command below:

- configure system time ntp server <NTP server ip address>authentication-key <key id> key <key> type message-digest
