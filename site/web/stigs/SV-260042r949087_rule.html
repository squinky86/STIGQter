The Enterprise Voice, Video, and Messaging Session Manager requiring user access authentication must provide a logout capability for user-initiated communications sessions.

If the Enterprise Voice, Video, and Messaging Session Manager requiring user access authentication does not provide a logout capability for user-initiated communications sessions, this is a finding.
