All guest VM network communications must be implemented using virtual network devices provisioned and serviced by the VMM.

Fix Recommendation

Add the guest VM networks. All interactions between guest VMs and external systems via other interface devices are mediated by the VMM or its service VMs.

1. Log in to Prism Element.
2. Click the gear icon in the upper-right corner.
3. Navigate to "Network Configuration".
4. Add the guest VM networks as defined by the organization.

Check Contents

Validate Nutanix CVM VM networking has been implemented and all of the virtual networks are defined and documented by the information system security officer (ISSO).

1. Log in to Prism Element.
2. Click the gear icon in the upper-right corner.
3. Navigate to "Network Configuration".

Validate that all of the organizational-defined guest VM networks are defined. If not, this is a finding.
