STIGQter: STIG Summary: HP FlexFabric Switch NDM Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 02 Jul 2025:

The HP FlexFabric Switch must enforce a minimum 15-character password length.

DISA Rule

SV-217452r1113774_rule

Vulnerability Number

V-217452

Group Title

SRG-APP-000164-NDM-000252

Rule Version

HFFS-ND-000053

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure the HP FlexFabric Switch to enforce a minimum 15-character password length.

[HP] password-control enable
[HP] password-control length 15

Check Contents

Determine if the HP FlexFabric Switch or its associated authentication server enforces a minimum 15-character password length.

[HP] display password-control

Global password control configurations:
Password control: Enabled
Password aging: Enabled (60 days)
Password length: Enabled (15 characters)

If the HP FlexFabric Switch does not have password control enabled and does not enforce a minimum 15-character password length, this is a finding.
