STIGQter: STIG Summary: Canonical Ubuntu 24.04 LTS Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

Ubuntu 24.04 LTS must accept Personal Identity Verification (PIV) credentials.

DISA Rule

Vulnerability Number

V-270672

Group Title

Rule Version

Severity

CAT II

CCI(s)

  • CCI-001953 - Accepts Personal Identity Verification-compliant credentials.

Weight

10

Fix Recommendation

Configure Ubuntu 24.04 LTS to accept PIV credentials.

Install the "opensc-pkcs11" package using the following command:

$ sudo apt install -y opensc-pkcs11

Check Contents

Verify the "opensc-pcks11" package is installed on the system with the following command:

$ dpkg -l | grep opensc-pkcs11
ii opensc-pkcs11:amd64 0.25.0~rc1-1build2 amd64 Smart card utilities with support for PKCS#15 compatible cards

If the "opensc-pcks11" package is not installed, this is a finding.
