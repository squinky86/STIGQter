STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Lookup Service Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

Lookup Service must be configured with the appropriate ports.

DISA Rule

SV-256734r888793_rule

Vulnerability Number

V-256734

Group Title

SRG-APP-000383-WSR-000175

Rule Version

VCLU-70-000029

Severity

CAT II

CCI(s)

  • CCI-001762 - Disable or remove organization-defined functions, ports, protocols, software, and services within the system deemed to be unnecessary and/or nonsecure.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-lookupsvc/conf/catalina.properties

Navigate to the port's specification section.

Set the Lookup Service port specifications according to the shipping configuration below:

base.shutdown.port=-1
base.jmx.port=-1
bio-custom.http.port=7090
bio-custom.https.port=8443

Restart the service with the following command:

# vmon-cli --restart lookupsvc

Check Contents

At the command prompt, run the following command:

# grep '\.port' /usr/lib/vmware-lookupsvc/conf/catalina.properties

Expected result:

base.shutdown.port=-1
base.jmx.port=-1
bio-custom.http.port=7090
bio-custom.https.port=8443

If the output of the command does not match the expected result, this is a finding.
