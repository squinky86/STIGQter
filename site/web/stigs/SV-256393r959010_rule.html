STIGQter: STIG Summary: VMware vSphere 7.0 ESXi Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 02 Apr 2025:

The ESXi host Secure Shell (SSH) daemon must not permit tunnels.

DISA Rule

SV-256393r959010_rule

Vulnerability Number

V-256393

Group Title

SRG-OS-000480-VMM-002000

Rule Version

ESXI-70-000025

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

From an ESXi shell, add or correct the following line in "/etc/ssh/sshd_config":

PermitTunnel no

Check Contents

From an ESXi shell, run the following command:

# /usr/lib/vmware/openssh/bin/sshd -T|grep permittunnel

Expected result:

permittunnel no

If the output does not match the expected result, this is a finding.
