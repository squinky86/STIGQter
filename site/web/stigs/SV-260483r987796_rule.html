STIGQter: STIG Summary: Canonical Ubuntu 22.04 LTS Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

Ubuntu 22.04 LTS must not have the "telnet" package installed.

DISA Rule

SV-260483r987796_rule

V-260483

Group Title

Severity

CCI(s)

  • CCI-000197 - For password-based authentication, transmit passwords only cryptographically-protected channels.

Weight

10

Fix Recommendation

Remove the "telnetd" package by using the following command:

$ sudo apt-get remove telnetd

Check Contents

Verify that the "telnetd" package is not installed on Ubuntu 22.04 LTS by using the following command:

$ dpkg -l | grep telnetd

If the "telnetd" package is installed, this is a finding.
