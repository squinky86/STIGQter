STIGQter: STIG Summary: Google Android 15 COPE Security Technical Implementation Guide Version: 1 Release: 5 Benchmark Date: 13 May 2026:

Google Android 15 devices must have a Mobile Threat Detection (MTD) app installed.

DISA Rule

SV-276995r1134426_rule

Vulnerability Number

V-276995

Group Title

PP-MDF-993300

Rule Version

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Install an MTD app on managed Google Android devices.

Check Contents

Confirm that an MTD app is installed on managed Google Android devices.

This check procedure is performed on both the device management tool and the Google Android device.

In the MDM console, verify that an MTD app is listed as a managed app being deployed to site managed devices.

On the Google Android device:

1. Open the Settings app.
2. Tap "Apps" and then "See all apps".
3. Verify that an MTD app is listed.

If an MTD app is not installed on the device, this is a finding.
