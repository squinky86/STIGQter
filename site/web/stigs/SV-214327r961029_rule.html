STIGQter: STIG Summary: Apache Server 2.4 Windows Server Security Technical Implementation Guide Version: 3 Release: 4 Benchmark Date: 01 Apr 2026:

The Apache web server must encrypt passwords during transmission.

DISA Rule

SV-214327r961029_rule

Vulnerability Number

V-214327

Group Title

SRG-APP-000172-WSR-000104

Rule Version

AS24-W1-000370

Severity

CAT II

CCI(s)

  • CCI-000197 - For password-based authentication, transmit passwords only cryptographically-protected channels.

Weight

10

Fix Recommendation

Edit the <'INSTALL PATH'>\conf\httpd.conf file and set the value of "SSLVerifyClient" to "require".

Restart the Apache service.

Check Contents

Review the <'INSTALL PATH'>\conf\httpd.conf file.

Ensure SSL is enabled by looking at the "SSLVerifyClient" directive.

If the value of "SSLVerifyClient" is not set to "require", this is a finding.
