STIGQter: STIG Summary: Oracle Linux 8 Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

OL 8 must restrict the use of "ptrace" to descendant processes.

DISA Rule

SV-248890r1156646_rule

Vulnerability Number

V-248890

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

OL08-00-040282

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure OL 8 to restrict usage of ptrace to descendant processes by adding the following line to "/etc/sysctl.d/99-sysctl.conf":

kernel.yama.ptrace_scope = 1

The system configuration files must be reloaded for the changes to take effect. To reload the contents of the files, run the following command:

$ sudo sysctl --system

Check Contents

Verify OL 8 restricts usage of ptrace to descendant processes with the following commands:

$ sysctl kernel.yama.ptrace_scope
kernel.yama.ptrace_scope = 1

If the returned line does not have a value of "1", or a line is not returned, this is a finding.
