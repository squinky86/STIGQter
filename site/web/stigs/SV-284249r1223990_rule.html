STIGQter: STIG Summary: Omnissa WS1 UEM Server Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 May 2026:

The Omnissa WS1 UEM server must limit the number of concurrent sessions per privileged user account to three or less concurrent sessions.

DISA Rule

SV-284249r1223990_rule

Vulnerability Number

V-284249

Group Title

SRG-APP-000001-UEM-000001

Rule Version

OMW1-00-000100

Severity

CAT II

CCI(s)

  • CCI-000054 - Limit the number of concurrent sessions for each organization-defined account and/or account type to an organization-defined number.

Weight

10

Fix Recommendation

Authenticate to the Workspace ONE UEM console as an administrator.

Navigate to Groups & Settings >> All Settings >> Admin >> Console Security >> Session Management.

Next to "Allow Multiple Sessions", click "Disabled". Click "Save".

Note: If this procedure is not seen on the console, the CSP is managing the setting. Contact the CSP to implement the required setting.

Check Contents
