STIGQter: STIG Summary: Google Android 14 MDFPP 3.3 BYOAD Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Oct 2025:

The Google Android 14 must allow only the administrator (EMM) to install/remove DOD root and intermediate PKI certificates (work profile).

DISA Rule

SV-260174r959010_rule

Vulnerability Number

V-260174

Group Title

PP-MDF-333350

Rule Version

GOOG-14-712300

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.
  • CCI-000370 - Manage configuration settings for organization-defined system components using organization-defined automated mechanisms.

Weight

10

Fix Recommendation

Configure Google Android 14 device to prevent a user from removing DOD root and intermediate PKI certificates (work profile).

On the EMM console:
1. Open "Set user restrictions".
2. Toggle "Disallow config credentials" to "ON".

Check Contents

Review the device configuration to confirm that the user is unable to remove DOD root and intermediate PKI certificates (work profile).

On the EMM console:
1. Open "Set user restrictions".
2. Verify "Disallow config credentials" is toggled to "ON".

On the Google Android 14 device:
1. Open Settings.
2. Tap "Security and privacy".
3. Tap "More security settings".
4. Tap "Encryption & credentials".
5. Tap "Trusted credentials".
6. Verify the user is unable to untrust or remove any work certificates.

If the user can remove certificates on the Google Android 14 device, this is a finding.
