STIGQter: STIG Summary: Cisco IOS Router RTR Security Technical Implementation Guide Version: 3 Release: 4 Benchmark Date: 01 Oct 2025:

The Cisco router must be configured to have Internet Control Message Protocol (ICMP) redirect messages disabled on all external interfaces.

DISA Rule

SV-216567r856186_rule

Vulnerability Number

V-216567

Group Title

SRG-NET-000362-RTR-000115

Rule Version

CISC-RT-000190

Severity

CAT II

CCI(s)

  • CCI-002385 - Protect against or limit the effects of organization-defined types of denial of service events.

Weight

10

Fix Recommendation

Disable ICMP redirects on all external interfaces as shown in the example below.

R4(config)#int g0/1
R4(config-if)#no ip redirects

Check Contents

Review the router configuration to verify that the no ip redirects command has been configured on all external interfaces as shown in the example below.

interface GigabitEthernet0/1
ip address x.x.x.x 255.255.255.0
no ip redirects

If ICMP Redirect messages are enabled on any external interfaces, this is a finding.
