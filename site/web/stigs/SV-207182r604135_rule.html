STIGQter: STIG Summary: Router Security Requirements Guide Version: 5 Release: 2 Benchmark Date: 28 Oct 2025:

The Multicast Source Discovery Protocol (MSDP) router must be configured to use its loopback address as the source address when originating MSDP traffic.

DISA Rule

Vulnerability Number

Severity

CAT III

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Ensure that the router’s loopback address is used as the source address when originating traffic.

Check Contents

Review the router configuration to verify that a loopback address has been configured.

Verify that a loopback interface is used as the source address for all MSDP packets generated by the router.

If the router does not use its loopback address as the source address when originating MSDP traffic, this is a finding.
