STIGQter: STIG Summary: HPE Nimble Storage Array NDM Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

HPE Alletra 5000/6000 must be configured to disable management by "HPE Greenlake: Data Services Cloud Console".

DISA Rule

SV-259801r960966_rule

Vulnerability Number

V-259801

Group Title

SRG-APP-000142-NDM-000245

Rule Version

HPEN-NM-000223

Severity

CAT II

CCI(s)

  • CCI-000382 - Configure the system to prohibit or restrict the use of organization-defined prohibited or restricted functions, system ports, protocols, software, and/or services.

Weight

10

Fix Recommendation

Disable Alletra cloud console.
Type "group --edit --cloud_management off".

If the response is as follows, contact your HPE sales account team to request approval:

"ERROR: Failed to change system configuration. Updating cloud management is not permitted."

Check Contents

Verify cloud console is disabled.
Type "group --info |grep -i "cloud enabled".

If the response is "cloud enabled: Yes", this is a finding.
