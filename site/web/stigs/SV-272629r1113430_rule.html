Fix Recommendation

Configure Cipher. Administrator privileges are required.

1. Log in to the admin console.
2. Navigate to CONFIGURATION >> Settings.
3. Find CylanceON-PREM Info >> Certificate Cipher.
4. Click "Change".
5. Select "Modern Mode (TS 1.2+)".
6. Click "Update".

Check Contents

Verify Cipher configuration. Administrator privileges are required.

1. Log in to the admin console.
2. Navigate to CONFIGURATION >> Settings.
3. Find CylanceON-PREM Info >> Certificate Cipher.

If the value is not set to Modern Mode (TLS 1.2+), this is a finding.
