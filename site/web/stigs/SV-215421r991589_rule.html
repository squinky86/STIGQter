STIGQter: STIG Summary: IBM AIX 7.x Security Technical Implementation Guide Version: 3 Release: 3 Benchmark Date: 01 Jul 2026:

AIX control scripts library search paths must contain only absolute paths.

DISA Rule

SV-215421r991589_rule

Vulnerability Number

V-215421

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

AIX7-00-003126

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Edit run control scripts' library search "PATH" variables. Remove empty entries or entries that are not absolute paths.

Check Contents

Verify run control scripts' library search paths:

# grep -r LIBPATH /etc/rc*
/etc/rc.teboot:export LIBPATH=/../usr/lib
/etc/rc.teboot:export LIBPATH=/usr/lib

This variable is formatted as a colon-separated list of paths.

If there is an empty entry, such as a leading or trailing colon, or two consecutive colons, this is a finding.

If an entry begins with a character other than a slash (/) or other than "$PATH", it is a relative path, and this is a finding.
