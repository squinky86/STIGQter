STIGQter: STIG Summary: IBM z/OS ACF2 Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

IBM z/OS must use ICSF or SAF Key Rings for key management.

DISA Rule

SV-223568r1225792_rule

Vulnerability Number

V-223568

Group Title

SRG-OS-000067-GPOS-00035

Rule Version

ACF2-OS-000330

Severity

CAT II

CCI(s)

  • CCI-000186 - For public key-based authentication, enforce authorized access to the corresponding private key.
  • CCI-000187 - For public key-based authentication, map the authenticated identity to the account of the individual or group.
  • CCI-004910 - Provide protected storage for cryptographic keys with organization-defined safeguards and/or hardware protected key store.

Weight

10

Fix Recommendation

Define all Keys/Certificates to ICSF or the security database. Remove any .kdb and .jks files.

Check Contents

Any keys or Certificates must be managed in ICSF or the external security manager and not in UNIX files.

From the ISPF Command Shell enter:
OMVS
enter
find / -name *.kdb
and
find / -name *jks
If any files are found, this is a finding.
