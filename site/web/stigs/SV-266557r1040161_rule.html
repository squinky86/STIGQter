STIGQter: STIG Summary: HPE Aruba Networking AOS Wireless Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Apr 2026:

AOS must use Transport Layer Security (TLS) 1.2, at a minimum, to protect the confidentiality of sensitive data during electronic dissemination using remote access.

CCI(s)

  • CCI-001453 - Implement cryptographic mechanisms to protect the integrity of remote access sessions.

Weight

10

Fix Recommendation

Configure AOS with the following commands:
configure terminal
web-server profile
ssl-protocol tlsv1.2
exit
write memory

Check Contents

Verify the AOS configuration with the following command:
show web-server profile

If "tlsv1.2" is not returned for "SSL/TLS Protocol Config", this is a finding.
