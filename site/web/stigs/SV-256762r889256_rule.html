STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance STS Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

The Security Token Service must fail to a known safe state if system initialization fails, shutdown fails, or aborts fail.

DISA Rule

SV-256762r889256_rule

Vulnerability Number

V-256762

Group Title

SRG-APP-000225-WSR-000140

Rule Version

VCST-70-000018

Severity

CAT II

CCI(s)

  • CCI-001190 - Fail to an organization-defined known-system state for the following failures on the indicated components while preserving organization-defined system state information in failure.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-sso/vmware-sts/conf/catalina.properties

Add or change the following line:

org.apache.catalina.startup.EXIT_ON_INIT_FAILURE=true

Restart the service with the following command:

# vmon-cli --restart sts

Check Contents

At the command line, run the following command:

# grep EXIT_ON_INIT_FAILURE /usr/lib/vmware-sso/vmware-sts/conf/catalina.properties

Expected result:

org.apache.catalina.startup.EXIT_ON_INIT_FAILURE=true

If the output of the command does not match the expected result, this is a finding.
