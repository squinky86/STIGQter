STIGQter: STIG Summary: BlackBerry Enterprise Mobility Server 3.x Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

If the BlackBerry Docs service is installed on the BlackBerry Enterprise Mobility Server (BEMS), it must be configured to enable the proxy server authentication type (if a proxy is used).

Weight

10

Fix Recommendation

Configure the Docs Web Proxy Authentication type within BEMS.

1. Under the "BlackBerry Services Configuration", select "Docs".
2. Select "Web Proxy Configuration".
3. Under "Proxy Server Authentication Type" Select "NTLM".

Check Contents

This requirement is not applicable if the Docs service for BEMS is not enabled.

Verify that the authentication type is set to NTLM if a web proxy is used.

1. Under the "BlackBerry Services Configuration", select "Docs".
2. Under the "Proxy Server Authentication Type", ensure "NTLM" is Selected.

If "NTLM" is not selected, this is a finding.
