STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 systemd-journald service must be enabled.

DISA Rule

SV-271739r1091929_rule

Vulnerability Number

V-271739

Group Title

SRG-OS-000269-GPOS-00103

Rule Version

OL09-00-002400

Severity

CAT II

CCI(s)

  • CCI-001665 - Preserve organization-defined system state information in the event of a system failure.

Weight

10

Fix Recommendation

Configure OL 9 to enable the systemd-journald service with the following command:

$ sudo systemctl enable --now systemd-journald

Check Contents

Verify that OL 9 systemd-journald is active with the following command:

$ systemctl is-active systemd-journald
active

If the systemd-journald service is not active, this is a finding.
