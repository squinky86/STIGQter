STIGQter: STIG Summary: IBM z/OS ACF2 Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

IBM z/OS PARMLIB CLOCKxx must have the Accuracy PARM coded properly.

DISA Rule

SV-223553r1225779_rule

Vulnerability Number

V-223553

Group Title

SRG-OS-000356-GPOS-00144

Rule Version

ACF2-OS-000170

Severity

CAT II

CCI(s)

  • CCI-004922 - Synchronize system clocks within and between systems or system components.
  • CCI-004926 - Synchronize the internal system clocks to the authoritative time source when the time difference is greater than organization-defined time period.

Weight

10

Fix Recommendation

Define the CLOCKxx statement to include the ACCURACY parm set to "1000".

Check Contents

Refer to the CLOCKxx member of PARMLIB.

If the ACCURACY parm is not coded, this is a finding.

If the ACCURACY parm is coded to "1000", this is not a finding.
