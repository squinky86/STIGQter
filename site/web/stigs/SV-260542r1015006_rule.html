STIGQter: STIG Summary: Canonical Ubuntu 22.04 LTS Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

Ubuntu 22.04 LTS must prevent direct login into the root account.

DISA Rule

SV-260542r1015006_rule

Vulnerability Number

V-260542

Group Title

SRG-OS-000109-GPOS-00056

Rule Version

UBTU-22-411010

Severity

CAT II

CCI(s)

  • CCI-004045 - Require users to be individually authenticated before granting access to the shared accounts or resources.

Weight

10

Fix Recommendation

Configure Ubuntu 22.04 LTS to prevent direct logins to the root account by using the following command:

$ sudo passwd -l root

Check Contents

Verify Ubuntu 22.04 LTS prevents direct logins to the root account by using the following command:

$ sudo passwd -S root
root L 08/09/2022 0 99999 7 -1

If the output does not contain "L" in the second field to indicate the account is locked, this is a finding.
