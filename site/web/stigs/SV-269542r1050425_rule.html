STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

AlmaLinux OS 9 audit tools must be owned by root.

DISA Rule

SV-269542r1050425_rule

Vulnerability Number

V-269542

Group Title

SRG-OS-000256-GPOS-00097

Rule Version

ALMA-09-056340

Severity

CAT II

CCI(s)

  • CCI-001493 - Protect audit tools from unauthorized access.
  • CCI-001495 - Protect audit tools from unauthorized deletion.

Weight

10

Fix Recommendation

Configure the audit tools to be owned by "root" by running the following command:

$ chown root [audit_tool]

Replace "[audit_tool]" with each audit tool not owned by "root".

Check Contents

Verify the audit tools are owned by "root" with the following command:

$ stat -c "%U %n" /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/rsyslogd /sbin/augenrules

root /sbin/auditctl
root /sbin/aureport
root /sbin/ausearch
root /sbin/autrace
root /sbin/auditd
root /sbin/rsyslogd
root /sbin/augenrules

If any audit tools do not have an owner of "root", this is a finding.
