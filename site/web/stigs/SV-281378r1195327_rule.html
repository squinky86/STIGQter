Fix Recommendation

Work with the system owner to develop a policy to ensure security patches and the application version are up to date.

1. Using a web browser, go to soaringsoftware.com.

2. Click "Contact", then "Contact Support", and enter user information. In the message, request to be added to the newsletter distribution.
