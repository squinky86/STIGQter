STIGQter: STIG Summary: NetApp ONTAP DSC 9.x Security Technical Implementation Guide Version: 2 Release: 4 Benchmark Date: 01 Jul 2026:

ONTAP must be configured to create a session lock after 15 minutes.

DISA Rule

SV-246923r1207671_rule

Vulnerability Number

V-246923

Group Title

SRG-APP-000003-NDM-000202

Rule Version

NAOT-AC-000002

Severity

CAT II

CCI(s)

  • CCI-000057 - The information system initiates a session lock after the organization-defined time period of inactivity.

Weight

10

Fix Recommendation

Configure the CLI timeout value to 15 minutes with the command, "system timeout modify -timeout 15".

Check Contents

Use "system timeout show" to check the current CLI timeout.

If the system timeout is not set to 15 minute(s) or less, this is a finding.
