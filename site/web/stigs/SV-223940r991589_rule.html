STIGQter: STIG Summary: IBM z/OS TSS Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

The CA-TSS Automatic Data Set Protection (ADSP) Control Option must be set to NO.

DISA Rule

SV-223940r991589_rule

Vulnerability Number

V-223940

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TSS0-ES-000670

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.
  • CCI-002358 - Implement a reference monitor for organization-defined access control policies that is always invoked.

Weight

10

Fix Recommendation

Configure the ADSP control option is set to (NO) indicating that the RACF bit in the DSCB will not be set. Evaluate the impact associated with implementation of the control option. Develop a plan of action to implement the control option setting to ADSP(NO) and proceed with the change.

Check Contents

From the ISPF Command Shell enter:
TSS MODIFY STATUS

If the ADSP Control Option value is not set to "ADSP(NO)", this is a finding.
