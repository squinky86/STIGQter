STIGQter: STIG Summary: Adobe ColdFusion Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Jul 2026:

ColdFusion must not install the Performance Monitoring Toolset (PMT) Agent Package.

DISA Rule

SV-279129r1171553_rule

Group Title

Severity

CAT II

CCI(s)

  • CCI-001199 - Protects the confidentiality and/or integrity of organization-defined information at rest.

Weight

10

Fix Recommendation

Uninstall the PMT Agent Package.

1. From the Admin Console Landing Screen, navigate to Package Manager>> Packages.

2. Select the "pmtagent" package.

3. Select "Uninstall".

4. Select "OK".

Check Contents

Verify the PMT Agent Package is not installed.

From the Admin Console Landing Screen, navigate to Package Manager>> Packages.

If the “pmtagent” package is listed under the "Installed Packages" section, this is a finding.
