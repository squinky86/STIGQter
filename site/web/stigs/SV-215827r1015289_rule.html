STIGQter: STIG Summary: Cisco IOS XE Router NDM Security Technical Implementation Guide Version: 3 Release: 7 Benchmark Date: 01 Apr 2026:

The Cisco router must be configured to enforce password complexity by requiring that at least one uppercase character be used.

DISA Rule

SV-215827r1015289_rule

Vulnerability Number

V-215827

Group Title

SRG-APP-000166-NDM-000254

Rule Version

CISC-ND-000570

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the Cisco router to enforce password complexity by requiring that at least one uppercase character be used as shown in the example below.

R1(config)#aaa common-criteria policy PASSWORD_POLICY
R1(config-cc-policy)#upper-case 1
R1(config-cc-policy)#exit
