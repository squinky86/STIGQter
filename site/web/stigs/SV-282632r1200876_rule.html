STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must disable storing core dumps.

DISA Rule

SV-282632r1200876_rule

Vulnerability Number

V-282632

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000112

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure TOSS 5 to disable storing core dumps for all users.

Add or modify the following line in /etc/systemd/coredump.conf:

Storage=none

Check Contents

Verify TOSS 5 disables storing core dumps for all users using the following command:

$ grep -i storage /etc/systemd/coredump.conf

Storage=none

If the "Storage" item is missing, commented out, or the value is anything other than "none" and the need for core dumps is not documented with the information system security officer (ISSO) as an operational requirement for all domains that have the "core" item assigned, this is a finding.
