STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

All AlmaLinux OS 9 local files and directories must have a valid group owner.

DISA Rule

SV-269189r1050071_rule

Vulnerability Number

V-269189

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

ALMA-09-012450

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Either remove all files and directories from AlmaLinux OS 9 that do not have a valid group, or assign a valid group to all files and directories on the system with the "chgrp" command:

$ chgrp <group> <file>

Check Contents

Verify all local files and directories on AlmaLinux OS 9 have a valid group with the following command:

$ df --local -P | awk {'if (NR!=1) print $6'} | xargs -I '{}' find '{}' -xdev -nogroup

If any files on the system do not have an assigned group, this is a finding.
