The Dell OS10 Switch must initiate session auditing upon startup.

  • CCI-000018 - Automatically audit account creation actions.
  • CCI-001403 - Automatically audit account modification actions.
  • CCI-001404 - Automatically audit account disabling actions.
  • CCI-001405 - Automatically audit account removal actions.

  • CCI-000130 - Ensure that audit records containing information that establishes what type of event occurred.

Weight

10

Fix Recommendation

Configure the OS10 Switch to initiate session auditing upon startup:

OS10(config)# logging audit enable

Check Contents

Check the OS10 Switch to determine if it initiates session auditing upon startup:

!
logging audit enable

If theOS10 Switch does not initiate session auditing upon startup, this is a finding.
