Security Token Service log files must only be modifiable by privileged users.

DISA Rule

SV-256751r889223_rule

Vulnerability Number

V-256751

Group Title

SRG-APP-000119-WSR-000069

Rule Version

VCST-70-000007

Severity

CAT II

CCI(s)

  • CCI-000163 - Protect audit information from unauthorized modification.
  • CCI-000164 - Protect audit information from unauthorized deletion.

Weight

10

Fix Recommendation

At the command prompt, run the following commands:

# chmod o-w <file>
# chown root:root <file>

Note: Substitute <file> with the listed file.

Check Contents

At the command prompt, run the following command:

# find /storage/log/vmware/sso/ -xdev -type f -a '(' -perm -o+w -o -not -user root -o -not -group root ')' -exec ls -ld {} \;

If any files are returned, this is a finding.
