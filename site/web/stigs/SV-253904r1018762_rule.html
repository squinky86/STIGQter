STIGQter: STIG Summary: Juniper EX Series Switches Network Device Management Security Technical Implementation Guide Version: 2 Release: 5 Benchmark Date: 01 Jul 2026:

The Juniper EX switch must be configured to enforce a minimum 15-character password length.

DISA Rule

SV-253904r1018762_rule

Vulnerability Number

V-253904

Group Title

SRG-APP-000164-NDM-000252

Rule Version

JUEX-NM-000270

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the network device or its associated authentication server to enforce a minimum 15-character password length.

set system login password minimum-length 15

Check Contents

Determine if the network device or its associated authentication server enforces a minimum 15-character password length. This requirement may be verified by demonstration or configuration review.

[edit system login password]
:
minimum-length 15;
:

If the network device or its associated authentication server does not enforce a minimum 15-character password length, this is a finding.
