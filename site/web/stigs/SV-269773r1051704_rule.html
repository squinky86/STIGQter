STIGQter: STIG Summary: Dell OS10 Switch NDM Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 10 Dec 2024:

The Dell OS10 Switch must protect against an individual (or process acting on behalf of an individual) falsely denying having performed organization-defined actions to be covered by nonrepudiation.

Weight

10

Fix Recommendation

Configure the OS10 Switch to enable audit logging:

OS10(config)# logging audit enable

Check Contents

Verify the OS10 Switch protects against an individual (or process acting on behalf of an individual) falsely denying having performed organization-defined actions to be covered by nonrepudiation.

Review the OS10 Switch configuration to determine if audit logging is enabled:

!
logging audit enable

If audit logging is not enabled, this is a finding.
