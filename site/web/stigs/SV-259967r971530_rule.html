STIGQter: STIG Summary: Enterprise Voice, Video, and Messaging Endpoint Security Requirements Guide Version: 1 Release: 3 Benchmark Date: 01 Oct 2025:

The Enterprise Voice, Video, and Messaging Endpoint must be configured to terminate all network connections associated with a communications session at the end of the session.

CCI(s)

  • CCI-001133 - Terminate the network connection associated with a communications session at the end of the session or after an organization-defined time period of inactivity.

Weight

10

Fix Recommendation

Configure the Enterprise Voice, Video, and Messaging Endpoint to terminate all network connections associated with a communications session at the end of the session.

Check Contents

Verify the Enterprise Voice, Video, and Messaging Endpoint terminates all network connections associated with a communications session at the end of the session.

If the Enterprise Voice, Video, and Messaging Endpoint does not terminate all network connections associated with a communications session at the end of the session, this is a finding.
