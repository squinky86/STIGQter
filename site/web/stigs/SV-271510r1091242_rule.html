STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must have the packages required for encrypting offloaded audit logs installed.

DISA Rule

SV-271510r1091242_rule

Vulnerability Number

V-271510

Group Title

SRG-OS-000120-GPOS-00061

Rule Version

OL09-00-000355

Severity

CAT II

CCI(s)

  • CCI-000803 - Implement mechanisms for authentication to a cryptographic module that meet the requirements of applicable laws, Executive Orders, directives, policies, regulations, standards, and guidance for such authentication.

Weight

10

Fix Recommendation

Install the rsyslog-gnutls package with the following command:

$ sudo dnf install -y rsyslog-gnutls

Check Contents

Verify that OL 9 has the rsyslog-gnutls package installed with the following command:

$ dnf list --installed rsyslog-gnutls
Installed Packages
rsyslog-gnutls.x86_64 8.2310.0-4.el9 @AppStream

If the rsyslog-gnutls package is not installed, this is a finding.
