STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 cron configuration directories must have a mode of 0700 or less permissive.

DISA Rule

SV-282641r1200903_rule

Vulnerability Number

V-282641

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000145

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure any TOSS 5 cron configuration directory with a mode more permissive than "0700" as follows:

$ sudo chmod 0700 [cron configuration directory]

Check Contents

Verify the permissions of the cron directories using the following command:

$ find /etc/cron* -type d | xargs stat -c "%a %n"

700 /etc/cron.d
700 /etc/cron.daily
700 /etc/cron.hourly
700 /etc/cron.monthly
700 /etc/cron.weekly

If any cron configuration directory is more permissive than "700", this is a finding.
