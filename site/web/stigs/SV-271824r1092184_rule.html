STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 audit tools must be group-owned by root.

DISA Rule

SV-271824r1092184_rule

Vulnerability Number

V-271824

Group Title

SRG-OS-000256-GPOS-00097

Rule Version

OL09-00-002570

Severity

CAT II

CCI(s)

  • CCI-001493 - Protect audit tools from unauthorized access.

Weight

10

Fix Recommendation

Configure the audit tools to be group-owned by "root" by running the following command:

$ sudo chgrp root [audit_tool]

Replace "[audit_tool]" with each audit tool not group-owned by "root".

Check Contents

Verify that OL 9 audit tools are group owned by "root" with the following command:

$ sudo stat -c "%G %n" /sbin/auditctl /sbin/aureport /sbin/ausearch /sbin/autrace /sbin/auditd /sbin/rsyslogd /sbin/augenrules
root /sbin/auditctl
root /sbin/aureport
root /sbin/ausearch
root /sbin/autrace
root /sbin/auditd
root /sbin/rsyslogd
root /sbin/augenrules

If any audit tools do not have a group owner of "root", this is a finding.
