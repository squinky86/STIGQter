Nutanix AOS must restrict error messages only to authorized users.

DISA Rule

Group Title

SRG-APP-000267-AS-000170

Rule Version

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Configure the user and group mappings to be compliant with the documented mapping policies defined by the ISSO.

1. Log in to Prism Element.
2. Click the gear icon in the upper-right corner.
3. Navigate to "Role mapping".
4. Add users and groups to role mappings per policy.

Check Contents

Nutanix VM application server supports user and group role mapping. Verify that all users or groups match that of the documented mapping policies defined by the information system security officer (ISSO).

1. Log in to Prism Element.
2. Click the gear icon in the upper-right corner.
3. Navigate to "Role mapping".

For each user or group listed, verify the role granted is in accordance with access control policies. If not, this is a finding.
