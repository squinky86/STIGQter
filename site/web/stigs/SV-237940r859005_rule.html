The IBM z/VM Portmapper server virtual machine userID must be included in the AUTOLOG statement of the TCP/IP server configuration file.

Fix Recommendation

Include the Portmapper server virtual machine userID in the "AUTOLOG" statement of the TCP/IP server configuration file.

The Portmapper server is then automatically started when TCP/IP is initialized. The IBM default userID for this server is PORTMAP, but review installation to assure proper ID is included.

Check Contents

Examine the TCP/IP configuration for "AUTOLOG".

If the userID for auto logger is not in the "AUTOLOG" statement of the TCP/IP server configuration file, this is a finding.
