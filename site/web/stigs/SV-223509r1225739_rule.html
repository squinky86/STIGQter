STIGQter: STIG Summary: IBM z/OS ACF2 Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

ACF2 TSOTWX GSO record values must be set to obliterate the logon password on TWX devices.

DISA Rule

SV-223509r1225739_rule

Vulnerability Number

V-223509

Group Title

SRG-OS-000079-GPOS-00047

Rule Version

ACF2-ES-000920

Severity

CAT II

CCI(s)

  • CCI-000206 - Obscure feedback of authentication information during the authentication process to protect the information from possible exploitation and use by unauthorized individuals.

Weight

10

Fix Recommendation

Define a cross out mask to obliterate the logon password on TWX devices.

CR(15)
IDLE(17)
LENGTH(8)
M1(X)
M2(N)
M3(Z)
M4(M)
STRING()

Example:
SET C(GSO)
INSERT TSOTWX CR(15) IDLE(17) LENGTH(8) M1(X) M2(N) M3(Z) M4(M) STRING()

F ACF2,REFRESH(TSOTWX)

ACF <enter>
SET CONTROL(GSO)
LIST TSOTWX
