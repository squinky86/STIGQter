STIGQter: STIG Summary: Microsoft Windows Server 2025 Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Jul 2026:

Windows Server 2025 must be configured to audit DS Access - Directory Service Changes failures.

DISA Rule

SV-278158r1182122_rule

Vulnerability Number

V-278158

Group Title

SRG-OS-000327-GPOS-00127

Rule Version

WN25-DC-000270

Severity

CAT II

CCI(s)

  • CCI-000172 - Generate audit records for the event types defined in AU-2 c that include the audit record content defined in AU-3.
  • CCI-002234 - Log the execution of privileged functions.

Weight

10

Fix Recommendation

Configure the policy value for Computer Configuration >> Windows Settings >> Security Settings >> Advanced Audit Policy Configuration >> System Audit Policies >> DS Access >> Directory Service Changes with "Failure" selected.

Check Contents

This applies to domain controllers. It is not applicable for other systems.

Security Option "Audit: Force audit policy subcategory settings (Windows 7 or later) to override audit policy category settings" must be set to "Enabled" (WN25-SO-000050) for the detailed auditing subcategories to be effective.

Use the "AuditPol" tool to review the current Audit Policy configuration.

Open PowerShell or a command prompt with elevated privileges ("Run as administrator").

Enter "AuditPol /get /category:*".

Compare the "AuditPol" settings with the following.

If the system does not audit the following, this is a finding:

DS Access >> Directory Service Changes - Failure
