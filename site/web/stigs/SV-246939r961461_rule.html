STIGQter: STIG Summary: NetApp ONTAP DSC 9.x Security Technical Implementation Guide Version: 2 Release: 4 Benchmark Date: 01 Jul 2026:

ONTAP must enforce access restrictions associated with changes to the device configuration.

CCI(s)

  • CCI-001813 - Enforce access restrictions using organization-defined mechanisms.

Weight

10

Fix Recommendation

Configure users with administrative privilege that allows device configuration with "security login create -user-or-group-name <user_name> -role admin".

Check Contents

Use "security login show -role admin" to see users with administrative privilege that allow device configuration.

If ONTAP does not enforce access restrictions associated with changes to the device configuration, this is a finding.
