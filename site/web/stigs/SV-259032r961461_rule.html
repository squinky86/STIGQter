STIGQter: STIG Summary: VMware vSphere 8.0 vCenter Appliance ESX Agent Manager (EAM) Security Technical Implementation Guide Version: 2 Release: 3 Benchmark Date: 01 Jul 2026:

The vCenter ESX Agent Manager service files must have permissions in an out-of-the-box state.

DISA Rule

SV-259032r961461_rule

Vulnerability Number

V-259032

Group Title

SRG-APP-000380-AS-000088

Rule Version

VCEM-80-000144

Severity

CAT II

CCI(s)

  • CCI-001813 - Enforce access restrictions using organization-defined mechanisms.

Weight

10

Fix Recommendation

At the command prompt, run the following commands:

# chmod o-w <file>
# chown root:root <file>

Note: Substitute <file> with the listed file.

Check Contents

At the command prompt, run the following command:

# find /usr/lib/vmware-eam/web/ -xdev -type f -a '(' -perm -o+w -o -not -user root -o -not -group root ')' -exec ls -ld {} \;

If any files are returned, this is a finding.
