STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must use a Linux Security Module configured to enforce limits on system services.

DISA Rule

SV-271452r1091068_rule

Vulnerability Number

V-271452

Group Title

SRG-OS-000445-GPOS-00199

Rule Version

OL09-00-000060

Severity

CAT I

CCI(s)

  • CCI-002696 - Verify correct operation of organization-defined security functions.
  • CCI-001084 - Isolate security functions from nonsecurity functions.

Weight

10

Fix Recommendation

Configure OL 9 to verify correct operation of security functions.

Edit the file "/etc/selinux/config" and add or modify the following line:

SELINUX=enforcing

A reboot is required for the changes to take effect.

Check Contents

Verify that OL 9 enforces the correct operation of security functions through the use of SELinux with the following command:

$ getenforce
Enforcing

If SELINUX is not set to "Enforcing", this is a finding.

Verify that SELinux is configured to be enforcing at boot.

$ grep "SELINUX=" /etc/selinux/config
# SELINUX= can take one of these three values:
# NOTE: In earlier Fedora kernel builds, SELINUX=disabled would also
SELINUX=enforcing

If SELINUX line is missing, commented out, or not set to "enforcing", this is a finding.
