The DNS server implementation must employ strong authenticators in the establishment of nonlocal maintenance and diagnostic sessions.

Fix Recommendation

Configure the DNS system to use multifactor authentication for nonlocal access for maintenance and diagnostics.

Check Contents

Review the DNS implementation's authentication methods and settings to determine if multifactor authentication is used to gain nonlocal access for maintenance and diagnostics.

If multifactor authentication is not used, this is a finding.
