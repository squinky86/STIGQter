STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 vendor packaged system security patches and updates must be installed and up to date.

DISA Rule

SV-282624r1200852_rule

Vulnerability Number

V-282624

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

TOSS-05-000085

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Install TOSS 5 security patches and updates at the organizationally defined frequency.

If system updates are installed via a centralized repository that is configured on the system, install all updates using the following command:

$ sudo dnf update

Check Contents

Verify TOSS 5 security patches and updates are installed and up to date. Updates are required in a frequency determined by organizational policy.

Check the TOSS release notes sent via email for security updates. It is important to note that updates provided by Red Hat/TOSS may not be present on the system if the underlying packages are not installed.

Check that the available package security updates have been installed on the system using the following command:

$ dnf history list | more

ID | Command line | Date and time | Action(s) | Altered
-------------------------------------------------------------------------------
70 | install aide | 2023-03-05 10:58 | Install | 1
69 | update -y | 2023-03-04 14:34 | Update | 18 EE
68 | install vlc | 2023-02-21 17:12 | Install | 21
67 | update -y | 2023-02-21 17:04 | Update | 7 EE

Typical update frequency may be overridden by Information Assurance Vulnerability Alert (IAVA) notifications from CYBERCOM.

If the system is not compliant with the organizational patching policy, this is a finding.
