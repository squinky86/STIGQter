STIGQter: STIG Summary: Mainframe Product Security Requirements Guide Version: 3 Release: 5 Benchmark Date: 01 Jul 2026:

The Mainframe Product must generate audit records containing the full-text recording of privileged commands or the individual identities of group account users.

DISA Rule

SV-205470r960909_rule

Vulnerability Number

V-205470

Group Title

SRG-APP-000101

Rule Version

Severity

CAT II

CCI(s)

  • CCI-000135 - Generate audit records containing the organization-defined additional information that is to be included in the audit records.

Weight

10

Fix Recommendation

Configure the Mainframe Product audit records written to external security manager audit files and/or SMF records to contain full-text recording of privileged commands or the individual identities of group account users.

Check Contents

Examine installation and configuration settings.

Verify data written to external security manager audit files and/or SMF records contain information that details contain full-text recording of privileged commands or the individual identities of group account users associated with the event. If it does not, this is a finding.
