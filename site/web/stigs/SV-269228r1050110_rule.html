STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

AlmaLinux OS 9 /etc/shadow- file must have mode 0000 or less permissive to prevent unauthorized access.

DISA Rule

SV-269228r1050110_rule

Vulnerability Number

V-269228

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

ALMA-09-016850

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the mode of the file "/etc/shadow-" to "0000" by running the following command:

$ chmod 0000 /etc/shadow-

Check Contents

Verify that the "/etc/shadow-" file has mode "0000" with the following command:

$ stat -c "%a %n" /etc/shadow-

0 /etc/shadow-

If a value of "0" is not returned, this is a finding.
