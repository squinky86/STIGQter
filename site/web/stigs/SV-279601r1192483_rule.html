STIGQter: STIG Summary: Nutanix Acropolis GPOS Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Jan 2026:

Nutanix OS must not install autofs.service.

DISA Rule

SV-279601r1192483_rule

Vulnerability Number

V-279601

Group Title

SRG-OS-000114-GPOS-00059

Rule Version

NXAC-OS-000157

Severity

CAT II

CCI(s)

  • CCI-000778 - Uniquely identify organization-defined devices and/or types of devices before establishing a local, remote, and/or network connection.

Weight

10

Fix Recommendation

Nutanix OS does not support the autofs.service by design. If autofs.service is enabled, some type of corruption has occurred and the OS must be rebuilt.

Check Contents

Verify Nutanix OS is configured to not automount devices using the following command.

$ sudo systemctl status autofs

If "autofs.sevice" is installed and or enabled, this is a finding.
