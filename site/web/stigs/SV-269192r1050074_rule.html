STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

AlmaLinux OS 9 /etc/group- file must be owned by root.

DISA Rule

SV-269192r1050074_rule

Vulnerability Number

V-269192

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

ALMA-09-012780

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the owner of the file /etc/group- to root by running the following command:

$ chown root /etc/group-

Check Contents

Verify the ownership of the "/etc/group-" file with the following command:

$ stat -c "%U %n" /etc/group-

root /etc/group-

If "/etc/group-" file does not have an owner of "root", this is a finding.
