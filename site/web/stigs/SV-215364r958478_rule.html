STIGQter: STIG Summary: IBM AIX 7.x Security Technical Implementation Guide Version: 3 Release: 3 Benchmark Date: 01 Jul 2026:

If AIX server does not host an SNMP agent, the dpid2 daemon must be disabled.

Severity

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

In "/etc/rc.tcpip", comment out the "dpid2" entry by running command:
# chrctcp -d dpid2

Check Contents

From the command prompt, execute the following command:
# grep "^start[[:blank:]]/usr/sbin/dpid2" /etc/rc.tcpip

If there is any output from the command, this is a finding.
