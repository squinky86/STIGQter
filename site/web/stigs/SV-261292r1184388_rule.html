STIGQter: STIG Summary: SUSE Linux Enterprise Micro (SLEM) 5 Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 01 Apr 2026:

All SLEM 5 local initialization files must have mode 740 or less permissive.

DISA Rule

SV-261292r1184388_rule

Vulnerability Number

V-261292

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

SLEM-05-232035

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Set the mode of SLEM 5 local initialization files to "740" with the following command:

Note: The example will be for the dosuser user, who has a home directory of "/home/dosuser".

> sudo chmod 740 /home/dosuser/.<INIT_FILE>

Check Contents

Verify that all SLEM 5 local initialization files have a mode of "740" or less permissive with the following command:

Note: The example will be for the user "dosuser", who has a home directory of "/home/dosuser".

> sudo ls -al /home/dosuser/.* | more
-rw-r-x---- 1 dosuser users 896 Mar 10 2011 .profile
-rw-r-x---- 1 dosuser users 497 Jan 6 27 .login
-rw-r-x---- 1 dosuser users 886 Jan 6 27 .something

If any local initialization files have a mode more permissive than "740", this is a finding.
