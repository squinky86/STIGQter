STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

All AlmaLinux OS 9 networked systems must have the OpenSSH client package installed.

Fix Recommendation

The openssh client package can be installed with the following command:

$ dnf install openssh-clients

Check Contents

Verify that AlmaLinux OS 9 has the openssh client package installed with the following command:

$ dnf list --installed openssh-clients

Installed Packages
openssh=clients.x86_64 8.7p1-28.el9 @anaconda

If the openssh client package is not installed, this is a finding.
