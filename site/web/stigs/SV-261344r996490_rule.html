STIGQter: STIG Summary: SUSE Linux Enterprise Micro (SLEM) 5 Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 01 Apr 2026:

There must be no shosts.equiv files on SLEM 5.

Fix Recommendation

Remove any "shosts.equiv" files found on SLEM 5.

> sudo rm /<path_to_file>/shosts.equiv

Check Contents

Verify there are no "shosts.equiv" files on SLEM 5 with the following command:

> sudo find /etc -name shosts.equiv

If any "shosts.equiv" files are found on the system, this is a finding.
