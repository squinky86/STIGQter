STIGQter: STIG Summary: RUCKUS ICX NDM Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 27 May 2025:

The RUCKUS ICX device must generate audit records containing the full-text recording of privileged commands.

DISA Rule

SV-273789r1110840_rule

Vulnerability Number

V-273789

Group Title

Rule Version

RCKS-NDM-000250

Severity

CAT II

CCI(s)

  • CCI-000135 - Generate audit records containing the organization-defined additional information that is to be included in the audit records.

Weight

10

Fix Recommendation

Enable CLI command logging:

SSH@ICX(config)# logging cli-command
SSH@ICX(config)# exit
SSH@ICX# write memory

Check Contents

Verify logging is enabled:

SSH@ICX(config)# show running-config | include logging
logging console
logging persistence
logging cli-command
logging host x.x.x.x
logging host y.y.y.y

If "logging cli-command" is not present or "no logging on" exists, this is a finding.
