STIGQter: STIG Summary: z/OS FDR for TSS Security Technical Implementation Guide Version: 7 Release: 2 Benchmark Date: 01 Oct 2025:

FDR (Fast Dump Restore) security options are improperly specified.

DISA Rule

SV-224718r1145975_rule

Vulnerability Number

V-224718

Group Title

SRG-OS-000018

Rule Version

ZFDR0040

Severity

CAT I

CCI(s)

  • CCI-000381 - Configure the system to provide only organization-defined mission essential capabilities.

Weight

10

Fix Recommendation

The systems programmer will verify that the security option ALLCALL is set to Yes.

Execute the FDR ISPF dialog by entering the following on the command line:

EXEC 'SYS2.FDR.VXXXX.CLIST(ABRALLOC)'

Select 'I' on the FDR PRIMARY OPTIONS MENU for INSTALL.

Select '4' on the INSTALLATION OPTIONS MENU to select SETOPT - SET INSTALLATION OPTIONS IN THE FDR GLOBAL OPTIONS TABLE.

Verify the FDR program library data set on this panel is set to the current LOADLIB. Example: 'SYS2A.FDR.Vxxxx.LOADLIB'.

Select '1' to select SECURITY OPTIONS.

On the SET FDR GLOBAL SECURITY OPTIONS, review the ALLCALL setting, ensure it is set to YES.

Check Contents

The following steps are necessary for reviewing the FDR options:

Issue the following command on the command line at option 6 in TSO to bring up the FDR ISPF dialog:

EXEC 'SYS2.FDR.Vxxxx.CLIST(ABRALLOC)'

Select 'I' on the FDR primary panel for INSTALL.
Select '4' on the FDR installation options panel to select SETOPT.
Verify the FDR Program Library Data Set on this panel specifies the following:
Example: 'SYS2A.FDR.Vxxxx.LOADLIB'.
Select '1' for SECURITY OPTIONS.
Review the setting for ALLCALL

Automated Analysis
Refer to the following report produced by the z/OS Data Collection:

- PDI(ZFDR0040).

If ALLCALL is set to YES, this is not a finding.
