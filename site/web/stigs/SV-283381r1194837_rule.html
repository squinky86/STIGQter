STIGQter: STIG Summary: HPE Alletra Storage ArcusOS Network Device Management Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Feb 2026:

The HPE Alletra Storage ArcusOS device must enforce a minimum 15-character password length.

DISA Rule

SV-283381r1194837_rule

Vulnerability Number

V-283381

Group Title

SRG-APP-000164-NDM-000252

Rule Version

ASMP-ND-000410

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure the minimum password length for a value of "15":

cli% setsys MinimumPWLength 15

Note: The user must have the "super" role to perform this action.

Check Contents

Verify the minimum password length is 15 characters with the following command:

cli% showsys -d

Minimum PW length 15

If the line containing the string "Minimum PW length" does not show "15" for the length, this is a finding.
