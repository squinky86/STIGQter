STIGQter: STIG Summary: Red Hat Enterprise Linux 9 Security Technical Implementation Guide Version: 2 Release: 9 Benchmark Date: 01 Jul 2026:

All RHEL 9 local interactive user home directories must be group-owned by the home directory owner's primary group.

DISA Rule

SV-258053r1208773_rule

Vulnerability Number

V-258053

Group Title

SRG-OS-000480-GPOS-00227

Rule Version

RHEL-09-411070

Severity

CAT II

CCI(s)

  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Change the group owner of a local interactive user's home directory to the group found in "/etc/passwd". To change the group owner of a local interactive user's home directory, use the following command:

Note: The example will be for the user "disauser", who has a home directory of "/home/disauser", and has a primary group of users.

$ sudo chgrp users /home/disauser

Check Contents

Verify the assigned home directory of all local interactive users is group-owned by that user's primary GID with the following command:

Note: This may miss local interactive users that have been assigned a privileged user identifier (UID). Evidence of interactive use may be obtained from a number of log files containing system logon information. The returned directory "/home/disauser" is used as an example.

$ getent passwd | awk -F: '($3>=1000 && $7!~/(nologin|false)$/){printf "User: %-15s Primary GID: %-5s Home: %s\n", $1, $4, $6}'
User: disauser Primary GID: 1002 Home: /home/disauser

Check the user's primary group with the following command:

$ stat -c "Directory: %n --> Actual GID: %g (%G)" /home/disauser
Directory: /home/disauser --> Actual GID: 1002 (disauser)

If the user home directory referenced in "/etc/passwd" is not group-owned by that user's primary GID, this is a finding.
