STIGQter: STIG Summary: Nokia Service Router OS 25.x Network Device Management Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 28 Apr 2026:

The Nokia router must record time stamps for audit records that can be mapped to Coordinated Universal Time (UTC) or Greenwich Mean Time (GMT).

DISA Rule

SV-283778r1203581_rule

Vulnerability Number

V-283778

Group Title

SRG-APP-000374-NDM-000299

Rule Version

NOKI-ND-000650

Severity

CAT II

CCI(s)

  • CCI-001890 - Record time stamps for audit records that use Coordinated Universal Time, have a fixed local time offset from Coordinated Universal Time, or that include the local time offset as part of the time stamp.

Weight

10

Fix Recommendation

Configure the Nokia router to record time stamps for audit records that can be mapped to UTC or GMT using the commands below:

- configure log log-id <log id>
- time-format utc

Check Contents

Verify a time zone is configured on the device, as shown in the example below:

- show log log-id <log id>
show log log-id 101

498 2025/11/10 18:35:48.230 UTC MINOR: USER #2011 management admin
"User from 10.2.0.2: NFS-Sr-2s# configure log syslog 1"

If the Nokia router does not record time stamps for audit records that can be mapped to UTC or GMT, this is a finding.
