STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 passwords, for new users, must have a minimum of 15 characters.

DISA Rule

SV-282468r1200384_rule

Vulnerability Number

V-282468

Group Title

SRG-OS-000078-GPOS-00046

Rule Version

TOSS-05-000345

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure TOSS 5 to enforce a minimum 15-character password length for new user accounts.

Add or modify the following line in the "/etc/login.defs" file:

PASS_MIN_LEN 15

Check Contents

Verify TOSS 5 enforces a minimum 15-character password length for new user accounts using the following command:

$ sudo grep -i pass_min_len /etc/login.defs

PASS_MIN_LEN 15

If the command does not return a "PASS_MIN_LEN" value of "15" or greater, does not return a line, or the line is commented out, this is a finding.
