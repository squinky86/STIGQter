STIGQter: STIG Summary: BlackBerry Enterprise Mobility Server 3.x Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

The BlackBerry Enterprise Mobility Server (BEMS) server must be configured to enable FIPS mode.

DISA Rule

SV-254729r879616_rule

Vulnerability Number

V-254729

Group Title

SRG-APP-000179-AS-000129

Rule Version

BEMS-03-014800

Severity

CAT II

CCI(s)

  • CCI-000803 - Implement mechanisms for authentication to a cryptographic module that meet the requirements of applicable laws, Executive Orders, directives, policies, regulations, standards, and guidance for such authentication.

Weight

10

Fix Recommendation

Enable FIPS Mode for BEMS.

1. In the BEMS Dashboard, under "BEMS Configuration", click "FIPS Mode".
2. Check the box "Enable FIPS Mode for Cluster".
3. Click "Save".

Check Contents

Verify FIPS Mode is enabled for BEMS.

1. Under BEMS Systems Settings select "BEMS Configuration".
2. Select "FIPS Mode".
3. Confirm "Enable FIPS Mode for Cluster" has been selected.

If "Enable FIPS Mode for Cluster" is not selected, this is a finding.
