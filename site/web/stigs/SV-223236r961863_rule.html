STIGQter: STIG Summary: Juniper SRX Services Gateway NDM Security Technical Implementation Guide Version: 3 Release: 3 Benchmark Date: 30 Jan 2025:

The Juniper SRX Services Gateway must be configured to use Junos 12.1 X46 or later to meet the minimum required version for DoD.

Fix Recommendation

Follow the manufacturer's instructions for upgrading the Junos version. Software updates must be from an approved site and follow approved DoD procedures and verification processes in accordance with site testing procedures.

Check Contents

Verify the version installed is Junos 12.1 X46 or later. In operational mode, type the following:

show version

If the Junos version installed is not 12.1 X46 or later, this is a finding.
