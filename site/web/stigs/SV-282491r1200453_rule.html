STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 groups must have unique Group ID (GID).

DISA Rule

SV-282491r1200453_rule

Vulnerability Number

V-282491

Group Title

SRG-OS-000104-GPOS-00051

Rule Version

TOSS-05-000309

Severity

CAT II

CCI(s)

  • CCI-000764 - Uniquely identify and authenticate organizational users and associate that unique identification with processes acting on behalf of those users.

Weight

10

Fix Recommendation

Edit the file "/etc/group" and provide each group that has a duplicate GID with a unique GID.

Check Contents

Verify TOSS 5 contains no duplicate GIDs for interactive users using the following command:

$ cut -d : -f 3 /etc/group | uniq -d

If the system has duplicate GIDs, this is a finding.
