STIGQter: STIG Summary: Microsoft Windows 11 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

The Application event log size must be configured to 32768 KB or greater.

DISA Rule

SV-253337r958752_rule

Vulnerability Number

V-253337

Group Title

SRG-OS-000341-GPOS-00132

Rule Version

WN11-AU-000500

Severity

CAT II

CCI(s)

  • CCI-001849 - Allocate audit log storage capacity to accommodate organization-defined audit record retention requirements.

Weight

10

Fix Recommendation

If the system is configured to send audit records directly to an audit server, this is NA. This must be documented with the ISSO.

Configure the policy value for Computer Configuration >> Administrative Templates >> Windows Components >> Event Log Service >> Application >> "Specify the maximum log file size (KB)" to "Enabled" with a "Maximum Log Size (KB)" of "32768" or greater.
