STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance EAM Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 26 Jul 2023:

ESX Agent Manager must set the secure flag for cookies.

DISA Rule

SV-256702r888662_rule

Vulnerability Number

V-256702

Group Title

SRG-APP-000380-WSR-000072

Rule Version

VCEM-70-000030

Severity

CAT II

CCI(s)

  • CCI-001813 - Enforce access restrictions using organization-defined mechanisms.

Weight

10

Fix Recommendation

Navigate to and open:

/usr/lib/vmware-eam/web/webapps/eam/WEB-INF/web.xml

Navigate to the /<web-apps>/<session-config>/<cookie-config> node and configure it as follows:

<cookie-config>
<http-only>true</http-only>
<secure>true</secure>
</cookie-config>

Restart the service with the following command:

# vmon-cli --restart eam

Check Contents

At the command prompt, run the following command:

# xmllint --format /usr/lib/vmware-eam/web/webapps/eam/WEB-INF/web.xml | sed 's/xmlns=".*"//g' | xmllint --xpath '/web-app/session-config/cookie-config/secure' -

Expected result:

<secure>true</secure>

If the output of the command does not match the expected result, this is a finding.
