STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must label all offloaded audit logs before sending them to the central log server.

DISA Rule

SV-282425r1201625_rule

Vulnerability Number

V-282425

Group Title

SRG-OS-000039-GPOS-00017

Rule Version

TOSS-05-000396

Severity

CAT II

CCI(s)

  • CCI-000132 - Ensure that audit records containing information that establishes where the event occurred.

Weight

10

Fix Recommendation

Edit the /etc/audit/auditd.conf file and add or update the "name_format" option:

name_format = hostname

Restart the audit daemon for changes to take effect.

Check Contents

Verify that TOSS 5 Audit Daemon is configured to label all offloaded audit logs, with the following command:

$ sudo grep name_format /etc/audit/auditd.conf

name_format = hostname

If the "name_format" option is not "hostname", "fqd", or "numeric", or the line is commented out, this is a finding.
