STIGQter: STIG Summary: VMware vSphere 7.0 vCenter Appliance Photon OS Security Technical Implementation Guide Version: 1 Release: 4 Benchmark Date: 30 Jan 2025:

The Photon operating system "/var/log" directory must be owned by root.

DISA Rule

SV-256515r958566_rule

Vulnerability Number

V-256515

Group Title

SRG-OS-000206-GPOS-00084

Rule Version

PHTN-30-000040

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

At the command line, run the following command:

# chown root:root /var/log

Check Contents

At the command line, run the following command:

# stat -c "%n is owned by %U and group owned by %G" /var/log

If the "/var/log directory" is not owned by root, this is a finding.
