STIGQter: STIG Summary: Cloud Linux AlmaLinux OS 9 Security Technical Implementation Guide Version: 1 Release: 7 Benchmark Date: 01 Jul 2026:

AlmaLinux OS 9 must require the maximum number of repeating characters of the same character class be limited to four when passwords are changed.

DISA Rule

SV-269396r1050279_rule

Vulnerability Number

V-269396

Group Title

SRG-OS-000072-GPOS-00040

Rule Version

ALMA-09-036980

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Configure AlmaLinux OS 9 to require the change of the number of repeating characters of the same character class when passwords are changed by setting the "maxclassrepeat" option.

Add the following line to "/etc/security/pwquality.conf" conf (or modify the line to have the required value):

maxclassrepeat = 4

Check Contents

Verify the value of the "maxclassrepeat" option in "/etc/security/pwquality.conf" with the following command:

$ grep -ir maxclassrepeat /etc/security/pwquality.conf*

/etc/security/pwquality.conf:# maxclassrepeat = 0
/etc/security/pwquality.conf.d/stig.conf:maxclassrepeat = 4

If the value of "maxclassrepeat" is set to "0", more than "4", or is commented out, this is a finding.
