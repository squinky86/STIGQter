STIGQter: STIG Summary: Google Chrome Current Windows Security Technical Implementation Guide Version: 2 Release: 11 Benchmark Date: 02 Jul 2025:

The version of Google Chrome running on the system must be a supported version.

DISA Rule

SV-221584r961683_rule

Vulnerability Number

V-221584

Group Title

SRG-APP-000456

Rule Version

DTBC-0050

Severity

CAT II

CCI(s)

  • CCI-002605 - Install security-relevant software updates within an organization-defined time period of the release of the updates.

Weight

10

Fix Recommendation

Install a supported version of Google Chrome.

Check Contents

Universal method:
1. In the omnibox (address bar) type chrome://settings/help
2. Cross-reference the build information displayed with the Google Chrome site to identify, at minimum, the oldest supported build available. As of July 2019, this is 74.x.x.
3. If the installed version of Chrome is not supported by Google, this is a finding.
