STIGQter: STIG Summary: Google Chrome Current Windows Security Technical Implementation Guide Version: 2 Release: 11 Benchmark Date: 02 Jul 2025:

Import AutoFill form data must be disabled.

DISA Rule

SV-226404r961083_rule

Vulnerability Number

V-226404

Group Title

SRG-APP-000206

Rule Version

DTBC-0072

Severity

CAT II

CCI(s)

  • CCI-001166 - Identify organization-defined unacceptable mobile code.

Weight

10

Fix Recommendation

Windows group policy:
1. Open the "group policy editor" tool with gpedit.msc
2. Navigate to Policy Path: Computer Configuration\Administrative Templates\Google\Google Chrome\
Policy Name: Import autofill form data from default browser on first run
Policy State: Disabled

Check Contents

Universal method:
1. In the omnibox (address bar) type chrome://policy
2. If ImportAutofillFormData is not displayed under the Policy Name column or it is not set to 0 under the Policy Value column, this is a finding.

Windows method:
1. Start regedit
2. Navigate to HKLM\Software\Policies\Google\Chrome\
3. If the ImportAutofillFormData value name does not exist or its value data is not set to 0, this is a finding.
