STIGQter: STIG Summary: Google Chrome Current Windows Security Technical Implementation Guide Version: 2 Release: 11 Benchmark Date: 02 Jul 2025:

Deletion of browser history must be disabled.

DISA Rule

SV-221586r960879_rule

Vulnerability Number

V-221586

Group Title

SRG-APP-000089

Rule Version

DTBC-0052

Severity

CAT II

CCI(s)

  • CCI-000169 - Provide audit record generation capability for the event types the system is capable of auditing as defined in AU-2 a. on organization-defined information system components.

Weight

10

Fix Recommendation

Windows group policy:
1. Open the group policy editor tool with gpedit.msc
2. Navigate to Policy Path: Computer Configuration\Administrative Templates\Google\Google Chrome\
Policy Name: Enable deleting browser and download history
Policy State: Disabled
Policy Value: N/A

Check Contents

Universal method:
1. In the omnibox (address bar) type chrome://policy
2. If the policy "AllowDeletingBrowserHistory" is not shown or is not set to false, this is a finding.

Windows method:
1. Start regedit
2. Navigate to HKLM\Software\Policies\Google\Chrome\
3. If the "AllowDeletingBrowserHistory" value name does not exist or its value data is not set to "0", this is a finding.
