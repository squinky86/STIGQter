STIGQter: STIG Summary: Juniper Router RTR Security Technical Implementation Guide Version: 3 Release: 2 Benchmark Date: 30 Jan 2025:

The Juniper router must be configured to have all inactive interfaces disabled.

DISA Rule

SV-217016r604135_rule

Vulnerability Number

V-217016

Group Title

SRG-NET-000019-RTR-000007

Rule Version

JUNI-RT-000060

Severity

CAT III

CCI(s)

  • CCI-001414 - Enforce approved authorizations for controlling the flow of information between connected systems based on organization-defined information flow control policies.

Weight

10

Fix Recommendation

Disable all inactive interfaces as shown below.

[edit interfaces]
set ge-1/1/0 disable

Check Contents

Review the router configuration and verify that inactive interfaces have been disabled as shown below.

interfaces {
ge-1/1/0 {
disable;
unit 0 {
}
}

If an interface is not being used but is configured or enabled, this is a finding.
