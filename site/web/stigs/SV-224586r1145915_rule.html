STIGQter: STIG Summary: z/OS BMC CONTROL-D for TSS Security Technical Implementation Guide Version: 7 Release: 2 Benchmark Date: 01 Oct 2025:

BMC CONTROL-D is not properly defined to the Facility Matrix Table for Top Secret.

DISA Rule

SV-224586r1145915_rule

Vulnerability Number

V-224586

Group Title

SRG-OS-000104

Rule Version

ZCTDT036

Severity

CAT II

CCI(s)

  • CCI-000764 - Uniquely identify and authenticate organizational users and associate that unique identification with processes acting on behalf of those users.

Weight

10

Fix Recommendation

The BMC CONTROL-D systems programmer and the ISSO will ensure that the TOP SECRET Facility Matrix Table is proper defined using the following example:

CONTROLD:
FAC(USERxx=NAME=CONTROLD,PGM=CTO,ID=nn,ACTIVE,SHRPRF)
FAC(CONTROLD=ASUBM,NOABEND,MULTIUSER,NOXDEF)
FAC(CONTROLD=LUMSG,STMSG,SIGN(S),WARNPW,NORNDPW)
FAC(CONTROLD=NOAUDIT,RES,NOTSOC,MODE=FAIL)
FAC(CONTROLD=LOG(SMF,INIT,MSG,SEC9),UIDACID=8,LOCKTIME=000)

Check Contents

Refer to the following reports produced by the TSS Data Collection:

- TSSCMDS.RPT(FACLIST) - Preferred report containing all control option values in effect including default values.
- TSSCMDS.RPT(TSSPRMFL) - Alternate report containing only control option values explicitly coded at TSS startup.

If the BMC CONTROL-D Facility Matrix table is defined as follows, this is a finding.

FAC(USERxx=NAME=CONTROLD,PGM=CTD,ID=nn,ACTIVE,SHRPRF)
FAC(CONTROLD=ASUBM,NOABEND,MULTIUSER,NOXDEF,SIGN(S))
FAC(CONTROLD=RES,LUMSG,STMSG,WARNPW,NORNDPW)
FAC(CONTROLD=NOAUDIT,NOTSOC,MODE=FAIL)
FAC(CONTROLD=LOG(SMF,INIT,MSG,SEC9),UIDACID=8,LOCKTIME=000)
