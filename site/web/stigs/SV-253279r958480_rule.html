STIGQter: STIG Summary: Microsoft Windows 11 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

The TFTP Client must not be installed on the system.

DISA Rule

Group Title

CCI(s)

  • CCI-000382 - Configure the system to prohibit or restrict the use of organization-defined prohibited or restricted functions, system ports, protocols, software, and/or services.

Weight

10

Fix Recommendation

Uninstall "TFTP Client" from the system.

Run "Programs and Features".
Select "Turn Windows Features on or off".
De-select "TFTP Client".

Check Contents

Verify TFTP Client has not been installed.

Navigate to the Windows\System32 directory.

If the "TFTP" application exists, this is a finding.
