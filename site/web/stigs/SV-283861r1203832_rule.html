STIGQter: STIG Summary: Nokia Service Router OS 25.x Router Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 28 Apr 2026:

The Nokia router must be configured to have Address Resolution Protocol (ARP) Learn Unsolicited disabled on all external interfaces.

DISA Rule

SV-283861r1203832_rule

Vulnerability Number

V-283861

Group Title

SRG-NET-000362-RTR-000111

Rule Version

NOKI-RT-000430

Severity

CAT II

CCI(s)

  • CCI-002385 - Protect against or limit the effects of organization-defined types of denial of service events.

Weight

10

Fix Recommendation

Disable ARP Learn Unsolicited on all external interfaces, as shown in the example below:

- configure router interface "TO-PE2" no arp-learn-unsolicited

Note: By default, arp-learn-unsolicited is disabled to deny GARP messages.

Check Contents

Review the configuration to determine if ARP Learn Unsolicited is disabled on all external interfaces.

Use the command below to verify the "ARP Learn Unsoli*" field for each configured interface is "Disabled":

- show router interface "TO-CE" detail | match "ARP Learn Unsoli*"
ARP Learn Unsoli*: Disabled ND Learn Unsolici*: None

If ARP Learn Unsolicited is enabled on any external interface, this is a finding.
