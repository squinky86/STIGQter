STIGQter: STIG Summary: Riverbed NetProfiler Security Technical Implementation Guide Version: 2 Release: 1 Benchmark Date: 24 Jul 2024:

The Riverbed NetProfiler must be configured to enforce a minimum 15-character password length.

DISA Rule

SV-256080r1015800_rule

V-256080

Group Title

Severity

CAT II

CCI(s)

  • CCI-004066 - For password-based authentication, enforce organization-defined composition and complexity rules.

Weight

10

Fix Recommendation

Go to Administration >> Account Management >> User Accounts.

Click the "Settings" button.

Under "Password Requirements", change the "Minimum number of characters" to "15".

Check Contents

Go to Administration >> Account Management >> User Accounts.

Click the "Settings" button.

Check under "Password Requirements".

If "Minimum number of characters" is set not to "15", this is a finding.
