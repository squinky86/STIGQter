STIGQter: STIG Summary: Red Hat Enterprise Linux 8 Security Technical Implementation Guide Version: 2 Release: 8 Benchmark Date: 01 Jul 2026:

A firewall must be active on RHEL 8.

DISA Rule

SV-244544r958672_rule

Vulnerability Number

V-244544

Group Title

SRG-OS-000297-GPOS-00115

Rule Version

RHEL-08-040101

Severity

CAT II

CCI(s)

  • CCI-002314 - Employ automated mechanisms to control remote access methods.

Weight

10

Fix Recommendation

Configure "firewalld" to protect the operating system with the following command:

$ sudo systemctl enable firewalld

Check Contents

Verify that "firewalld" is active with the following commands:

$ sudo systemctl is-active firewalld

active

If the "firewalld" package is not "active", ask the System Administrator if another firewall is installed. If no firewall is installed and active this is a finding.
