Fix Recommendation

Configure appropriate logs:

- exit all
- configure log log-id <id>
- from main, security, and change
- to <console, syslog-id, snmp, log-file-id, memory, session, netconf, cli>

Note: Select the appropriate location for the log event data from the options above.
