STIGQter: STIG Summary: Akamai KSD Service Impact Level 2 NDM Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 12 Sep 2017:

The Akamai Luna Portal must employ Security Assertion Markup Language (SAML) to automate central management of administrators.

DISA Rule

SV-91197r1_rule

Vulnerability Number

V-76501

Group Title

SRG-APP-000516-NDM-000337

Rule Version

AKSD-DM-000117

Severity

CAT I

CCI(s)

  • CCI-000366 - Implement the security configuration settings.
  • CCI-000371 - Apply configuration settings for organization-defined system components using organization-defined automated mechanisms.

Weight

10

Fix Recommendation

Configure logins to require SAML integration.

1. Log in to the Akamai Luna Portal (Caution-https://control.akamai.com).
2. Click "Configure" >> "Manage SSO with SAML"
3. Click the "Enable" button next to the "SAML-only login:" label.
4. Click "Yes" when asked if you want to enable SAML-only login.

Check Contents

Confirm that only SAML logins are enabled.

1. Log in to the Akamai Luna Portal (Caution-https://control.akamai.com).
2. Click "Configure" >> "Manage SSO with SAML"
3. Verify "SAML-only login:" is set to "enabled"

If the "SAML only logins:" is set to disabled, this is a finding.

NOTE: During the initial deployment and testing of the Luna Portal implementation, it will be necessary to allow other logins. However, production environments must meet this requirement.
