STIGQter: STIG Summary: HP FlexFabric Switch RTR Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 24 Jul 2020:

The HP FlexFabric Switch must not redistribute static routes to alternate gateway service provider into an Exterior Gateway Protocol or Interior Gateway Protocol to the NIPRNet or to other Autonomous System.

DISA Rule

SV-80589r1_rule

Vulnerability Number

V-66099

Group Title

SRG-NET-000019-RTR-000011

Rule Version

HFFS-RT-000002

Severity

CAT II

CCI(s)

  • CCI-001414 - Enforce approved authorizations for controlling the flow of information between connected systems based on organization-defined information flow control policies.

Weight

10

Fix Recommendation

By default the HP FlexFabric switches do not redistribute static routes via External/Internak gateway protocols. If Static routes redistribution has been configure, use the command bellow to disable it.

[HP] ospf 1
[HP-ospf-1] undo import-route static

Check Contents

Review the External/internal gateway protocol database on the HP FlexFabric Switch to ensure no static routes are being redistributed via these protocols.

If there are static routes being re-distributed, this is a finding.
