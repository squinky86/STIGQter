STIGQter: STIG Summary: ISEC7 Sphere Security Technical Implementation Guide Version: 3 Release: 1 Benchmark Date: 24 Oct 2024:

The ISEC7 SPHERE server must be configured to have at least one user in the following Administrator roles: Security Administrator, Site Administrator, and Help Desk User.

DISA Rule

SV-224764r1013808_rule

Vulnerability Number

V-224764

Group Title

SRG-APP-000090

Rule Version

ISEC-06-000270

Severity

CAT II

CCI(s)

  • CCI-000171 - Allow organization-defined personnel or roles to select the event types that are to be logged by specific components of the system.

Weight

10

Fix Recommendation

Log in to the ISEC7 SPHERE console.
Navigate to Administration >> Configuration >> Access Permissions.
Assign at least one user or AD group to each of the following roles: Security Administrator, Site Administrator, and Help Desk User.

Check Contents

Log in to the ISEC7 SPHERE console.
Navigate to Administration >> Configuration >> Access Permissions.
Verify for each Role (Security Administrator, Site Administrator, and Help Desk User) that at least one user or AD group has been assigned.

If for each Role (Security Administrator, Site Administrator, Help Desk User) there is not at least one user (or AD group) assigned, this is a finding.
