STIGQter: STIG Summary: Oracle Linux 9 Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

OL 9 must enable the USBGuard package.

DISA Rule

SV-271504r1091224_rule

Vulnerability Number

V-271504

Group Title

SRG-OS-000378-GPOS-00163

Rule Version

OL09-00-000321

Severity

CAT II

CCI(s)

  • CCI-001958 - Authenticate organization-defined devices and/or types of devices before establishing a local, remote, and/or network connection.

Weight

10

Fix Recommendation

Enable the USBGuard service with the following command:

$ sudo systemctl enable --now usbguard

Check Contents

Verify that OL 9 USBGuard is enabled with the following command:

$ systemctl is-active usbguard
active

If usbguard is not active, ask the SA to indicate how unauthorized peripherals are being blocked.

If there is no evidence that unauthorized peripherals are being blocked before establishing a connection, this is a finding.
