STIGQter: STIG Summary: Symantec Edge SWG NDM Security Technical Implementation Guide Version: 1 Release: 2 Benchmark Date: 01 Apr 2026:

The Edge SWG must be running an operating system release that is currently supported by the vendor.

Fix Recommendation

1. Log in to the Broadcom Symantec Support Portal: https://support.broadcom.com/group/ecx/products.
2. Click "My Downloads".
3. Select "Cyber Security Software".
4. Search for "ISG Proxy" for the software downloads specific to Edge SWG (proxy) on ISG.
5. Expand the ISG Proxy, then scroll down for the builds.
6. Select the release to be downloaded (using 7.4.7.2 as an example) to be directed to the page containing the builds.

Check Contents

1. Log in to the Edge SWG SSH CLI.
2. Enter "show version".

If this version is not the same as the latest supported image showing on the Broadcom support site: https://support.broadcom.com/group/ecx/products, this is a finding.
