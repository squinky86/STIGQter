STIGQter: STIG Summary: IBM z/OS ACF2 Security Technical Implementation Guide Version: 9 Release: 9 Benchmark Date: 01 Jul 2026:

CA-ACF2 must prevent the use of dictionary words for passwords.

DISA Rule

SV-223477r1225707_rule

Vulnerability Number

V-223477

Group Title

SRG-OS-000480-GPOS-00225

Rule Version

ACF2-ES-000590

Severity

CAT II

CCI(s)

  • CCI-004061 - For password-based authentication, verify when users create or update passwords, that the passwords are not found on the list of commonly-used, expected, or compromised passwords in IA-5 (1) (a).
  • CCI-004065 - For password-based authentication, employ automated tools to assist the user in selecting strong password authenticators.
  • CCI-000366 - Implement the security configuration settings.

Weight

10

Fix Recommendation

Configure the GSO record to include PSWDRSV and PSWDRSVW.

Check Contents

From the ISPF Command Shell enter:
ACF to enter ACF2 Command shell
enter SHOW STATE

If "PSWDRSV = NO", this is a finding.

If "PSWDRSVW = NO", this is a finding.

SHOW PSwdopts

Reserved Words and Prefixes
APPL APR ASDF AUG BASIC
CADAM DEC DEMO FEB FOCUS
GAME IBM JAN JUL JUN
