STIGQter: STIG Summary: SPEC Innovations Innoslate 4.x Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 08 Sep 2022:

Innoslate must generate comprehensive audit records.

DISA Rule

SV-254092r845252_rule

Vulnerability Number

V-254092

Group Title

SRG-APP-000091

Rule Version

SPEC-IN-000140

Severity

CAT II

CCI(s)

  • CCI-000130 - Ensure that audit records containing information that establishes what type of event occurred.
  • CCI-000131 - Ensure that audit records containing information that establishes when the event occurred.
  • CCI-000132 - Ensure that audit records containing information that establishes where the event occurred.
  • CCI-000172 - Generate audit records for the event types defined in AU-2 c that include the audit record content defined in AU-3.
  • CCI-001464 - Initiates session audits automatically at system start-up.

Weight

10

Fix Recommendation

1. Locate the logging.properties file in the following directory: Innoslate4\apache-tomcat\conf.
2. Search "level" and modify corresponding lines to be set to FINE or VERBOSE as needed.

Check Contents

1. Locate the logging.properties file in the following directory: Innoslate\apache-tomcat\conf.
2. Search "level", and check corresponding lines for the correct verbosity settings. If they are incorrect after a change, save, and service restart, this is a finding.
