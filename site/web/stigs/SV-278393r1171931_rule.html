NGINX must identify prohibited mobile code.

CCI(s)

  • CCI-001166 - Identify organization-defined unacceptable mobile code.
  • CCI-001662 - Take organization-defined corrective action when organization-defined unacceptable mobile code is identified.
  • CCI-001169 - Prevent the download of organization-defined unacceptable mobile code.
  • CCI-001170 - Prevents the automatic execution of mobile code in organization-defined software applications.

Weight

10

Fix Recommendation

Determine the path to NGINX config file(s):

# nginx -qT | grep "# configuration"
# configuration file /etc/nginx/nginx.conf:

Note: The default NGINX configuration is "/etc/nginx/nginx.conf", though various files may also be included.

Remove any unnecessary or unpermitted modules from the configuration.

After saving the configuration, reload NGINX:

# nginx -s reload
