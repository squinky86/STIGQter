STIGQter: STIG Summary: Mozilla Firefox Security Technical Implementation Guide Version: 6 Release: 8 Benchmark Date: 01 Jul 2026:

Firefox must prevent the user from quickly deleting data.

DISA Rule

SV-251562r1156569_rule

Vulnerability Number

V-251562

Group Title

SRG-APP-000326

Rule Version

FFOX-00-000018

Severity

CAT II

CCI(s)

  • CCI-000166 - Provide irrefutable evidence that an individual (or process acting on behalf of an individual) falsely denying having performed organization-defined actions to be covered by non-repudiation.

Weight

10

Fix Recommendation

Windows group policy:
1. Open the group policy editor tool with "gpedit.msc".
2. Navigate to Policy Path: Computer Configuration >> Administrative Templates >> Mozilla >> Firefox.
Policy Name: Disable Forget Button
Policy State: Enabled

macOS "plist" file:
Add the following:
<key>DisableForgetButton</key>
<true/>

Linux "policies.json" file:
Add the following in the policies section:
"DisableForgetButton": true

Check Contents

Enter "about:policies" in the browser address bar.

If "DisableForgetButton" is not displayed under Policy Name or the Policy Value is not "true", this is a finding.
