STIGQter: STIG Summary: Riverbed NetIM OS Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 11 Sep 2025:

Ubuntu OS must not have the "telnet" package installed.

DISA Rule

SV-275577r1147781_rule

V-275577

Group Title

Rule Version

Severity

CAT I

CCI(s)

  • CCI-000197 - For password-based authentication, transmit passwords only cryptographically-protected channels.

Weight

10

Fix Recommendation

Remove the "telnetd" package by using the following command:

$ sudo apt-get remove telnetd

Check Contents

Verify the "telnetd" package is not installed on Ubuntu OS by using the following command:

$ dpkg -l | grep telnetd

If the "telnetd" package is installed, this is a finding.
