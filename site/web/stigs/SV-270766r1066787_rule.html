STIGQter: STIG Summary: Canonical Ubuntu 24.04 LTS Security Technical Implementation Guide Version: 1 Release: 6 Benchmark Date: 01 Jul 2026:

Ubuntu 24.04 LTS must configure the /var/log directory to be owned by root.

DISA Rule

SV-270766r1066787_rule

Vulnerability Number

V-270766

Group Title

SRG-OS-000206-GPOS-00084

Rule Version

UBTU-24-700110

Severity

CAT II

CCI(s)

  • CCI-001314 - Reveal error messages only to organization-defined personnel or roles.

Weight

10

Fix Recommendation

Configure Ubuntu 24.04 LTS to have root own the /var/log directory by running the following command:

$ sudo chown root /var/log

Check Contents

Verify Ubuntu 24.04 LTS configures the /var/log directory to be owned by "root" with the following command:

$ stat -c "%n %U" /var/log
/var/log root

If the "/var/log" directory is not owned by root, this is a finding.
