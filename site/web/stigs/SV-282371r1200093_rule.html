STIGQter: STIG Summary: Tri-Lab Operating System Stack (TOSS) 5 Security Technical Implementation Guide Version: 1 Release: 1 Benchmark Date: 26 Mar 2026:

TOSS 5 must limit the number of concurrent sessions to 256 for all accounts and/or account types.

DISA Rule

SV-282371r1200093_rule

Vulnerability Number

V-282371

Group Title

SRG-OS-000027-GPOS-00008

Rule Version

TOSS-05-000313

Severity

CAT III

CCI(s)

  • CCI-000054 - Limit the number of concurrent sessions for each organization-defined account and/or account type to an organization-defined number.

Weight

10

Fix Recommendation

Configure TOSS to limit the number of concurrent sessions to 256 or less for all accounts and/or account types.

Add the following line to the top of the "/etc/security/limits.conf" or in a ."conf" file defined in "/etc/security/limits.d/":

* hard maxlogins 256

Check Contents

Verify TOSS limits the number of concurrent sessions to 256 or less for all accounts and/or account types using the following command:

$ sudo grep -r -s '^[^#].*maxlogins' /etc/security/limits.conf /etc/security/limits.d/*.conf
* hard maxlogins 256

This can be set as a global domain (with the * wildcard) but may be set differently for multiple domains.

If the "maxlogins" item is missing, commented out, or the value is set greater than "256" and is not documented with the information system security officer (ISSO) as an operational requirement for all domains that have the "maxlogins" item assigned, this is a finding.
